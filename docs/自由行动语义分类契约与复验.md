# 自由行动语义分类契约与复验

日期：2026-11-12。套题 `ds-action-kernel-semantics-1`。本轮只新增研究判据及未使用过的措辞，不改生产规则、提示、模型版本、SDK入口或旧黄金。

## 1. 采样前冻结的判据

| 关注点 | 本套题契约 |
| --- | --- |
| 原始字段 | verb / target / item 必须精确匹配预设字符串；预期空串不是通配。缺失、null、数字均不等于空串。 |
| 地点等价 | place 原始值仅可为空串或本次 before 的当前地点 ID；不接受异地、未知地点、空白、大小写变体、null 或缺字段。不回写或修改模型原文。 |
| 动作识别 | 明确当下的白名单动作，即使已持有、缺食物、钱不足、效果已用，仍预设保留原动词和对象，由规则作专用拒绝。 |
| unsupported | 没有当前要做的动作、明确推迟实施、未提供的移动入口、复制或超能力、读取未公开秘密等。不是资源前置不满足的万能替代码。 |
| 规则后果 | 具体拒绝原因、有无骰、耗时及物权单独检查；不能用 Kernel committed、零效果或安全拒绝冒充动作分类正确。 |

这是一份**研究的公开分类契约**，不是已经接入生产的额外指令，也不声称现有提示无歧义。生产说明同时含“能力内应提出尝试”和“不能执行时用unsupported”，本轮检验原提供方在该边界的表现，不在采样后移动判据。预注册中的 target / item 沿用旧案例数据的 null 表示“固定预期空串”，匹配时不是通配；模型实际返回 null 仍不通过。

## 2. 固定范围

- 20 个独立案例与同一世界 4 步连续行动，复用 063 的资源状态及真实本地准备方法，但全部更换措辞。
- 银币耗尽、鱼已吃掉、织物已施效由先前脚本行动真实提交；三种先前骰败保留原生种子7、原物件和已发生的耗时。脚本准备不是模型能力。
- 连续行动仍为重复取随身锁 → 再取同一锁 → 买鱼 → 再买同一串鱼。下一 before 必须等于上一 after，不重置状态或补资源。
- 在创建联网提供方前保存案例、序列、before 摘要与 `semantic-contract.pre-registered.json`。同一批最多24次，仅玩家 Adjudicate 联网，无自动重试、无换模型。
- 主入口是 `Session.ActAsync(input, ct, transaction)`。原文旧路径对照不联网；ready 候选经独立摘要锚和真实 Kernel 严格回放。有限隐私差分与canary不等于全面安全证明。

### 4.1 保留的四项分类失败

| 案例 | 固定预期 | 实际响应 |
| --- | --- | --- |
| `semantics_nonexistent_food` | feed / whelp / smoked_fish；`item_missing` | unsupported / 空对象，`intent_unsupported` |
| `semantics_already_held` | take / 空目标 / iron_lock；`take_item_invalid` | unsupported / 空对象，`intent_unsupported` |
| `semantics_sequence_1` | take 同一把随身铁锁；`take_item_invalid` | unsupported / 空对象，`intent_unsupported` |
| `semantics_sequence_2` | 再 take 同一把铁锁；`take_item_invalid` | unsupported / 空对象，`intent_unsupported` |

四项都是安全拒绝、无骰、零耗时、完整世界不变；叙述能提到原动作，但结构化动词没保留，故仍判失败。不能用安全拒绝抹去分类差异，也不能把本研究的分类约定说成产品已经修复。

四步连续链逐步承接同一世界：前两项分类失败但状态不变；第三项真实买鱼扣三银币，鱼归玩家；第四项正确保留 buy，并由 `seller_absent` 拒绝，没有再次扣钱。联合检查为 **2/4**，不是四次都通过。

### 4.2 事后补核与证据限制

只读审查提醒“无骰零耗时拒绝”还应核整个快照，而不只看单个物权。本轮采样后对所有已保存结果补做独立全量 JSON 对照：离线9项、真实12项无骰零耗时拒绝均 before == after、Changes为空、receipt.Applied=false；四步链全部哈希承接。证据 `.local/action-semantics/full-snapshot-posthoc-audit.json` 明确标为**事后补核**，不改预注册、原始 summary 或正式20/24，也不冒充此前已自动计入的判据。

本批未产生错误地点、错误类型、缺字段或错误对象响应，相关防假绿由离线负例覆盖，而非真实模型对抗成绩。52项源码及3个加载程序集在正式离线/真实批分别一致，52项源码与收尾磁盘逐项相同。
