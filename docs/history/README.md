## 不归档的文件

- 论文详细解读：独立研究参考，不是旧游戏方案。
- 工程骨架说明、项目进度：描述当前实现事实，确认后更新入口与差距。
- OpenAI 接入与成本规范、AGENTS、协作规范：安全与流程约束不因换设计失效。
- 全部开发日志和索引：按日期保留事实；旧链接修复，不重写历史验收。
- 源码、Unity 资源、素材台账与原始来源记录：不是此次文档整理对象。

## 移动时的验收

1. 修改前重新检查 Git 状态，保留其他任务改动；逐文件移动，不批量覆盖目录。
2. 历史文件保留正文，在头部标历史状态、日期与新入口。
3. 重新计算被移动文件自己的相对链接，更新 README、当前文档、日志索引与资产说明中的引用；不只移动后留下断链。
4. 检查相对路径及章节锚点、`git diff --check`，依仓库规范运行离线回归；日志记录实际移动清单。
5. 确认当前“最新方案”只剩 v5 一套，历史内容可访问但不会被误认为已实现或仍待制作。
