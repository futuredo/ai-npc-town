## 如何查旧事实

- 删除前代码可在 Git 提交 `2747b47` 查阅；这只是明确的整理前快照，**不是本轮重新验收过的旧玩法版本**。本轮未创建归档 tag，也不恢复旧玩法继续测试。
- [开发日志](../开发日志/README.md) 按日期保留原决定、成功与失败，不改写旧测试数字来凑现行数量。旧文档移动时只修复链接与增加历史标记。
- `art/` 的来源、许可证、筛选和导入审计不随旧玩法一起删除。被忽略的商业源素材、玩家存档、密钥、预算账本也不在退役范围。
- 历史链接指向的 `.local/` 临时报告或旧派生场景可能已按授权清理；缺失不应通过重跑旧验证补回。当前实验与严格回放证据继续保留。

本次实施与实际验证见 [043 旧原型退役与工程整理](../开发日志/2026-11-09_043_旧原型退役与工程整理.md)。
