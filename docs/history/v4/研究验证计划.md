## 1. 研究目标与游戏目标

主研究问题：**论文中的六类机制分别怎样接入游戏引擎，实际增加什么玩家能力与世界变化，哪些组合有趣、可靠且成本可接受？** 语义裁定与自主互动是首个闭环，不再作为唯一研究类型；受限 GM 与功能造物也有本 Demo 的独立切片和证据。定义与边界见[接入计划 §3](AI原生互动验证计划.md#3-六类机制具体落在哪里)。

记忆子问题：角色需要记住什么，才能不把谣言当事实，并在证据变化后作出可追溯的修正？记忆不能代替语义裁定与自主互动的主目标。

游戏问题：玩家是否愿意调查、协商、构造并试验一种引路办法，把芬恩和漂流灯送过断鳞？是否有具体想改造/重试的想法，而非不断读对白等结果？完整献灯故事暂作扩展，不是先完成的体验前提。

两个目标分别验收：规则测试不能证明模型理解；模型回答流畅不能证明行动兑现；技术指标改善也不能代替真人觉得选择有意义。

## 2. 不可越过的边界

1. **模型参与语义裁定，程序校验并执行。** 模型可在未来沙盒决定社会回应与候选计划，程序保留权限、硬事实与状态一致性；不把所有软性社会结果预先决定后只交给模型润色。世界事实、角色认知、角色台词分层；输出不是已发生事件。
2. 仅向模型发送当前角色的 `NpcPerceptionView` 与必要玩家输入。不发送世界真值、他人秘密或本地文件。
3. 认知写入必须带来源、时间与纠错关系；同源转述不能算独立证据。
4. 结构、引用、被纠正信息及文字泄露都要检查。被拒原始输出与安全兜底分别统计，不能以兜底掩盖模型失败。
5. 异步检查局代际和版本；旧局回复写入、重复执行、密钥泄露均为零容忍项。
6. 当前接口仅对话、`action=none`。未来意图解析先展示解释并由玩家确认，再进入类型化命令；尚未批准模型任意执行世界动作。
7. 新裁定/决策、事件提案和构造接口待定义权限与独立启用。当前只允许角色 `NpcPerceptionView` 与必要输入；未来 GM 专属公开事件视图须另批准，全知主持者、任意工具执行和跨角色私有快照不因定位修正获准。

## 3. 对照组与公平性

分开三个比较：**原生依赖/分机制贡献**，六类分别开关或规则替代，观察丢失的行动与体验；**B/C 记忆**，相同机制能力只换记忆；**组合体验取舍**，比较不同机制组合的等待、误解、主动试法与重试意愿。不能混成一个成功率，也不要求复杂组合优于简单组合。具体见[接入计划 §9](AI原生互动验证计划.md#9-怎样检验不是六个聊天皮肤)。

| 组 | 定位 | 模型可见记忆 | 当前状态 |
| --- | --- | --- | --- |
| A 规则 | 离线基线、测试预言与服务不可用时的安全路径 | 规则读取结构化认知 | 已可运行，不是 AI 效果数据 |
| B 近期上下文 | 基础记忆条件 | 当前角色近期对话与可知事件，固定截断策略 | 待实现 |
| C 来源记忆 | 主研究条件 | 相关命题、来源、时间、被纠正标记的检索结果 | 待实现 |

B/C 使用同一模型、请求预算、输出上限、场景种子、输入序列、可执行命令和裁决规则，**只改变记忆组织/检索策略**。A 不应被包装成同一种模型条件。

不得通过“B 关闭识破、C 开启识破”证明来源记忆更好：那同时改了游戏规则。识破规则两组一致；比较模型能否正确指出原说话者、引用依据、提出可校验的纠错或对质。若确实移除来源字段或关闭机制，单列为**信息/机制消融**，不与记忆检索对照混为一谈。

同一条谎言的可检验链路：玩家假称亲眼看见 → 居民采信 → 获得更强反证 → 模型是否归因正确 → 校验器是否接受 → 规则是否兑现后果。每一段分别记录，不只报最后成功率。

## 4. 用例与证据

先用录制响应跑通 Runner，再申请真实小样本。计划场景而非本轮已完成实验：

| 类别 | 代表反例 | 观察对象 |
| --- | --- | --- |
| 知识边界 | 不知井底、他人心事、未知位置；提示注入要求泄露 | 原始回答、引用、拦截与兜底 |
| 纠错与时效 | 旧基线偷锤/归还回归；新场景“献灯是唯一办法”获得真实反例、光源已转移 | 区分事实、历史解释与尚未证实的安全推断；旧认知是否仍被采用 |
| 来源与传播 | 同一梅芙消息绕一圈；假称亲眼；独立目击 | 原始来源归因、同源误判、识破依据 |
| 意图理解 | 同义句、含糊对象、反悔、拒绝确认 | 解析/澄清与实际命令，不把台词算执行 |
| 行动兑现 | 旧归还任务回归；新借光/临时保护、参与者拒绝、路径或法术锚点不成立 | 接受→执行→完成/失败与可见反馈；魔法不是无限许愿 |
| 工程反例 | 超时、取消、断网、重开/读档后旧回包 | 状态不污染、记录完整、不隐式重试收费 |
| 开放方法 | 提示词和专用分支中未出现的方法、条件交换、他人尚未同意 | 有理由的裁定/澄清/反提议、实际效果；不以服从率当理解率 |
| 自主决策 | 新消息到达、目标受阻、两个承诺冲突；玩家不逐步发令 | 由模型选择的求证/协助/回避轨迹、角色局部信息边界 |
| 持续约定 | 临时约定、反悔、失约、版本变化与存读档 | 条件与完成标准是世界状态，重放不重复推理或付费 |
| 受限主持 | 根据不同已发生事件组合后续目标，缺少对象/资源，诱导倒改历史或泄露秘密 | 新局面可玩且因果有关；提案校验/执行后才计发生，不以旁白变化计完成 |
| 功能构造 | 未预设的组件连接/布置、材料不足、循环/越界结构，生成脚本要求 | 对象图、材料账、碰撞与功能实测，至少两种功能差别；不能仅文案/图片/换预制体名 |

记录场景 ID、规则版本、模型、检索条件、随机种子、输入序列、认知快照指纹、校验结果、任务轨迹、耗时与 usage。离线复现与真实在线调用分开标记；实验数据不包含密钥，完整原始请求不写入 Unity 资源或发布包。

## 5. 指标与判定

- **知识**：越权披露率、过时信息采用率、证据纠错率、来源归因准确率、同源误判率。
- **意图/行动**：正确解析率、澄清次数、规则拒绝原因、任务完成率。区分“模型说做了”和程序真的完成。
- **原生机制**：保留方法的有依据回应与条件质量、实际支持的方法差异、角色主动行动与后续影响、约定持续性。与仅改措辞、固定剧情分支分别计数；合理拒绝也计入评审，不只统计成功结果。
- **分类型增量**：N1 调查/纠错，N2 协商/履约，N3 可执行后续的因果性，N4 未见方法裁定，N5 自主因果链，N6 构型/功能差异，各有分母与失败例；不以一次输出的多个标签冒领独立验证。
- **工程**：旧回复污染/重复执行计数、取消成功率、失败可恢复性、存读档状态一致性。
- **性能/成本**：P50/P95 响应时间、输入输出 token、每局调用次数、按 usage 与现行价格计算的**估算费用**。无 usage 就标未知，不填零。
- 先登记用例与通过条件，再运行；报告样本数、分母、失败例与置信区间。小样本只作可行性观察，不推断统计显著或泛化能力。

## 6. 体验验收：不要只做会答题的胶囊体

验收以[核心计划 §8](核心体验与推进计划.md#8-怎样判定它值得继续做)的主动试法、构型改造、因果解释与重试意愿为主，同时检查[接入计划 §9](AI原生互动验证计划.md#9-怎样检验不是六个聊天皮肤)的分机制证据。技术与体验分别记录；外部短测不等全章/美术完成，离线试玩不包装成真实 AI 体验。

- 首次玩家不读设计文档，先对一个奇观或法术产生主动探索，能说出芬恩眼前的困局；在用到见证时再检查是否理解独立源头，不以先背规则代替动机。
- 能分清“我的猜测 / 听谁说的 / 我亲眼看见”，传话前能看懂自己在承担什么后果。
- 玩家提出或改变一种方法，亲手试一次魔法，能说明角色是否同意、实际发生什么；诚实与伪造来源另列机制反例，不要求首次试玩者照演两条攻略。
- 角色说话有个性，拒绝/等待有理由，导航失败不装作已完成；手记、对话与场景交互不互相抢焦点。
- 正式 UI、世界线稿、落墨节奏、音效与芬恩变化是待实现的体验工作，不因缺正式模型就取消，也不把 IMGUI 当最终交付。

试玩记录：录屏，加“最想靠近的奇观/想改的造物是什么”，以及四问“是否理解了我 / 是否影响了结果 / 等待是否打断体验 / 是否愿意继续或重玩”；再问“试验为什么成功或失败 / 伙伴为什么这样行动 / 哪里开始枯燥”。目标至少 3 位、争取 5 位外部试玩者；尚未开展，不虚构反馈。

## 7. 成本闸门与当前证据

日常开发、Play、单元测试与回放均不收费。真实请求需用户明确授权，默认 `gpt-6-luna`，不自动升级、重试或搜索。首轮最多 3 次、输出每次最多 384 tokens、输入请求体最多 12 KiB、并发 1；单轮预算 USD 0.01，UTC 日最多 20 次/USD 0.05，每次先预留 USD 0.002。失败超时计次，不重置预算文件。以[OpenAI 规范](../../OpenAI接入与成本规范.md)及仓库约定为准。

已有实现证据是 **100 项离线 .NET 测试、5 项 Unity PlayMode 测试与两条 Sandbox 路线**；本次定位修正没有新增模型请求。尚无六机制依赖性、B/C、真实裁定/主持/造物/自主社会或真人“好玩”结论。按 D0—D4 先跑一个小闭环，再补六类切片与组合对照；3 次首轮请求不能充当六类全验证，后续扩批须另获授权。
