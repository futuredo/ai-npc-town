**建议用一个工坊资源包定环境的造型，再围绕白龙、半影少年、玻璃蛾和鹿骨骑士做少量特色改造。** 第一批优先比较下面六项；同用途是备选关系，不建议一起买齐。

## 7. UE → Unity / URP 的整理方式

用户接受转换后，**UE-only 不再是淘汰条件**。但只把实际能取得的内容计入资源价值：

| 类型 | 本项目计划接收的交付 | 需要单独验证/重做 |
| --- | --- | --- |
| 静态模型 | FBX、独立贴图、比例/轴向记录 | 枢轴、法线、碰撞、LOD、模型拆分与 URP 材质 |
| 蒙皮角色 | 带蒙皮网格、骨架、逐段动画，必要的 Morph | 人形 Avatar / 非人 Generic 映射；眨眼和额外骨骼；动画事件与 Root Motion |
| 材质 | BaseColor、Normal、ORM 或各分量、Emissive、Opacity 的来源说明 | 通道拆包、Smoothness、法线方向、透明/裁剪、双面、发光与光照 |
| UE 专用表现 | 只登记为效果参考和可复用纹理 | Blueprint、Niagara、材质图、Light Function、Lumen/烘焙场景效果在 Unity 重建 |

这是转换范围划分，不是已做过的转换结论。通用 FBX 管道能力参考 [Epic 官方文档][T01]；Unity 官方也区分[内置材质转换和自定义 Shader 改写][T02]。不因一键导出成功就标记“美术已验收”。

## 8. 首批验证组合与采购顺序

**推荐先比较环境 A/B，再锁一套。** 环境 A = U01；环境 B = F01。两者都围绕同一段龙鳞、同一盏月灯、同一个角色评估；不要以商品演示场景各自拍得好看代替同场景对照。

1. **环境与世界奇观**：U01 或 F01 + 一段自制鳞片 + 月灯代理。确认“站在龙背上”一眼能看懂，再决定是否获取 U02 的龙头/翼。
2. **角色识别**：Q01 芬恩 + F02 梅芙候选；瑟恩先做四足/直立剪影对照，霍勒斯比较 F08/F09。测试角色在实际镜头下有多大，避免小角色堆高面数。
3. **一次法术表现**：定页、有限影桥或月焰中的一项，先配一只 F03 玻璃蛾；可观察成功/拒绝/取消/失效，不先全套 VFX。
4. **再扩展内容**：Moon Temple、整座月井、森林、完整龙体演出后置。真实玩法稳定后再补音乐与专属环境音。

## 10. 到包后的实际验收

- 下载时记录版本、文件名、来源、许可证副本与哈希；商店候选和项目已取得资产分开。
- 先取 **一张工作台、一个角色、一只蛾** 做 URP 小场景。角色待机/行走/施法，蛾原地扇翼，工作台放可交互灯；统一光照下观察比例、材质与细节。
- 1080p 与 720p 检查半影、断角、月灯和接点辨识；纸纹不闪烁、透明蛾翼不消失、不依赖颜色才能分辨状态。
- 看脚滑、斗篷穿插、鹿角遮挡、眨眼、动画循环、导航与交互高度；看实际三角面、材质数、透明叠加和帧耗。
- 通过导入检查只能标 `import_verified=true`；实际场景画面/动作通过后才标 `in_game_approved=true`。当前所有候选两项均为 false。
