## 2. 独立入口及状态

套件 `ds-continuous-world-t3-1`，唯一正式目录：


1. **离线先行**：同种子分别执行无包装参考臂与包装臂；比较完整最终世界及每步 kind/actor/input/raw/error/failure/verdict/craft decision/receipt，排除计时和模拟usage。离线全部完成且完全相同才可预注册。
2. **预注册一次性**：冻结种子、夜数、上限、模型、角色视角、12 KiB、768 tokens、停止条件、观测项、费用未知规则、离线证据哈希及研究/Core/OpenAI源码清单与SHA。注册不能覆盖，来源文件增删改也拒绝；离线期间源码变化会使基线失败。
3. **整批锁**：Prepare/live争用根目录同一`live.lock`；live从校验到汇总一直持锁。`STARTED`、既有attempts或live目录阻止再次开始；中断批也不能重启。失败不另起目录，不删除标记。
4. **委托边界**：每次先核验注册及payload（冻结角色快照安全重建＋隐私差分）、检查每seed25/全批75、持久追加一次尝试，再调用inner。上限与原`FileRequestBudget(SixMechanismResearch)`叠加，不替换、不重置预算账本。
5. **失败停止**：Error保持原对象/原码；null、空白、抛异常统一产生可回放失败结果，不保存异常正文。首次故障写STOPPED，原管线生成失败trace；trace/replay/before/after先保存，然后观察器抛停止。没有观察器时，同夜下一次也会在inner前拒绝；runner不会开始下一seed。超时/失败已经计次，无retry。

## 3. 私有报告口径

每个已完成trace保存：原`*.trace.json`、`*.replay.json`、`*.before.local.json`、`*.after.local.json`、合法`*.payload.json`、`*.audit.local.json`和`*.chain.local.json`。

- **结构/引用**：从原始raw独立检查Schema与引用，不能用规则剔除后的proposal算绿。非法引用与实际规则拒绝/Partial分别记录。
- **实际规则结果**：verdict、reason/code/notes、receipt、世界差异；自动意图与人工语义审阅保留null，Accepted/committed不等于意图正确。
- **回放/隐私**：strictReplay、receipt前后哈希、实际角色payload重建一致；他人私有belief文本/True＋私有chronicle差分，另列同地他人私有差分；无同地他人时注明空命题。这里只是有限差分证明，不是一般隐私安全证明。
- **社会链**：本地before/after完整保留`root / hops / source / owner / root_owner`及新增认知，不向模型额外发送跨角色链或世界真值。既有冻结视角内本人认知的来源字段不被改写。
- **GM**：原提案事件、实际`gm.event`、白名单、大小事件额度前后及额度检查、是否最终黎明、mother提出/实际提交、WithMother分别记录。无实际事件时额度/母龙规则检查是null，不伪造通过。
- **每夜覆盖**：`continuous-report.local.json`逐夜逐居民标记observed/not_called，夜间GM与final-dawn GM分列。不调用不是成功样本。
- **费用**：只有非模拟返回input/output usage且有估算值才累计真实估算；缺usage为未知，已知部分和总额分开。离线RuleProvider模拟tokens只列`simulated_usage`，整批`estimated_usd=null`，不能说真实费用0。75次×USD0.002=USD0.15只是预留，不是实际费用估算或余额证据。

### 判定分层与分母

1. **schema/reference失败是模型输出结果，不等同于invariant失败**。`schema_valid`、`references_valid`和`structural_reference_valid`独立记录；失败样本仍保留在实际尝试/结果分母，不删除、不重抽、不补跑。只要provider正常且回放、隐私、回执等不变量成立，结构/引用失败本身不会触发整批STOPPED。
2. **invariants**只检查严格回放、回执哈希、角色payload一致、有限隐私差分与canary，不包含schema/reference成功条件。GM实际提交越过白名单/额度/最终母龙规则另触发停机。不能把`invariants=true`写成结构或意图通过。
3. **provider故障或护栏/不变量故障立即整批停止**；首次失败保留已计尝试，之后未调用居民/GM标记not_called，不伪造成失败输出或成功输出。
4. **造物依赖断裂是流程停止原因**：即使只是结构/规则失败导致未获道具，也会按原Journey停止依赖链，不伪造补道具；这与provider故障分类不同。
5. `automatic_intent_match=null`、`manual_semantic_review=null`表示**尚未判定**，不是通过，也不进入“已通过意图”分子。Accepted、Partial、committed、回放成功、结构成功均不能替代语义意图判定。
