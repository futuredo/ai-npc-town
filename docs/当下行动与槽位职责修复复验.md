- 候选为显式 `ds-action-prompt-v3`（`DsActionPrompt.Focused`）；`Current` 仍指生产提示v2，Game仍使用v2。

- 复用四类玩法、三个固定种子、每臂四步，共最多96次真实请求；顺序固定交替，不是随机试验。每步使用上一步的实际世界与私有历史，不补物、不重置、不重抽。

## 成绩不能互相替代

1. **逐步意图**：verb／target／item严格字符串匹配；place仅原空串或当前地点ID等价，空值和缺字段不通配。
2. **关键动作实际后果**：每臂observe九次、wait三次必须确实Accepted、Roll=1、耗时2并Applied；confide三次需正确槽位并实际耗时1；无食物lure三次保持正确当下意图，但不保证骰成。
3. **重复挑战**：只有首步真的消耗、交付、施效或买到时，第二步才适用；未形成不算通过，最终目标不抵销重复操作错误。
4. **规则不变量与回放**：同原文旧规则路径、完整世界／回执对照及真实Kernel ready候选回放独立报告；无ready记录不能算回放通过。
5. **玩法目标**：实际跟随、结盟、找到契约、交易后物权等单列，不把提前搜索取得契约当成忠实观察。

候选生产考虑门槛在采样前固定：以上四组关键动作全部通过。未过时不启用到Game；即使通过，也不能据已知失败集声称普遍正确。

## 两臂分叉与解释范围

每步保存世界before哈希与完整冻结感知的哈希；计算感知对照时只移除历史记录中的`request_id`，不移除动作、对象、裁决、时刻、名称或物权后果。

- `same_world_and_history`：同世界且同语义历史，仅提示说明不同。
- `history_diverged`：世界相同但历史已有差别，后续差异不能仅归当前提示。
- `world_diverged`：世界已不同，只保留为连续玩法结果。

四步通常只发送0–3条历史，四条是容量上限，不能补齐历史伪造对照。相同世界也不保证相同记忆。

### 冻结证据、源码一致性与限制

- 核对预注册`focus-contract.pre-registered.json`、`.local/action-focus/live-run.pre-registered.json`、十二个`fixtures.local-only/*.json`及全部96组result／trace／before／after／frozen-prompt／payload／replay／anchor。完整before／after哈希、回执effects与实际全世界差异、原始提案、usage、连续历史均交叉相符；不是只抄summary。
- 每臂只有一种冻结说明，v3严格为v2追加通用`FocusedInstructions`；输出Schema一致。41个同上下文对的sections与冻结感知文本亦相同。`source-manifest.json`的`files` **56项**、`assemblies` **3项**，本次只读核对时全部与当前文件SHA256相同；三个程序集为Research的Release/net8.0目录下`Town.Core.dll / Town.PieGame.dll / PieGame.AI.Kernel.dll`。预注册的两项源码哈希也与manifest相同。
- manifest顶层`actionPromptVersion=v2`是当前默认版本，不能误读为只运行v2；`promptArms`及每步frozen／trace明确记录v2、v3。清单未冻结`Town.Research.dll`、Unity场景／UI／桥接程序集；哈希一致不等于执行过这些入口。56项源码包含请求构造及策略文件，但payload是本地构造记录，不是服务端请求或账单抓包。
- 实际世界种子固定为**109、110、111**，控制世界与规则掷骰，不是模型随机seed；manifest遗留顶层seed=7932不替代十二夹具种子。全部payload无模型seed、temperature或tools；固定交替顺序非随机试验，不声称独立重复、可复现相同模型文本或未见泛化。
- 模型为`gpt-6-luna`，研究配置单并发、输出上限768、请求体上限12,288字节、自动重试0，无升级／兜底。落盘payload压紧UTF-8长度v2为5,269–5,983字节、v3为6,687–7,401字节，实际单次输出最多75 tokens；`store=false`、严格JSON Schema、reasoning=none。限制由请求代码实施，不能把四步短链当作长期吞吐或服务端上限验证。
- 出站内容与冻结玩家`TaskPerceptionView`及必要玩家输入一致，无完整世界／居民私有认知字段；本批96项检查未见既有私有标记。此次未增加“只改隐藏真值”的独立差分探针，不能把标记阴性扩大为一般非干扰证明。
- 规则不变量96/96；同原文旧路径96/96的含义按研究比较器：完整世界及回执一致，唯一host_rejected节点只按已声明映射归一receipt.status，原failure、规则评估及其余回执仍核对，不笼统忽略错误。
- 共**95/95**个ready候选落盘严格回放通过，帧fingerprint、raw摘要、before／after与本地anchor一致；另1个v2 host_rejected无帧。这里引用研究运行时真实Kernel的重算结果，只读整理不再执行回放；anchor与录制同保存在本机，不是独立可信外部审计。候选回放不证明玩家意图正确、完整历史来源或Unity实况。
- **生产私有数据边界未改变**：`KernelActionTransaction`在Game也为每个ready保留含raw的私有ReplayFrame，不是研究专用开关；不能加入公开receipt／trace／模型提示。列表随事务对象生命周期保留，不随Kernel Reset清空；Kernel请求before保留到Reset，无容量淘汰。此次每链四步未检验长局内存治理，Game也未提供严格Replay入口。`kernel_code=committed`只表示候选生命周期提交，可能是规则拒绝的no_change，不能当成动作Applied或意图成功。
