# 《回音镇》v2 核心玩法实现

日期：2026-11-05　分支：feature/npc-schedule-relations　关联 PR / 提交：未提交

## 目的与范围

按当时的 `玩法设计_回音镇_v2.md` 第 11 节「必做」实现可离线玩通的一整天：日程与闲聊、传话（如实 / 说成亲眼所见 / 添油加醋 / 不说）、偷听、同源不叠加、誓钟显化与回音石板、芬恩亲手还锤、承诺、道歉、秘密与信任、拜师牵线、钟响结算（命名结局、小报、流言溯源）。B 线灯灵的最小版（看井 + 传话）也一并实现，因为誓钟需要它。

> 历史说明：v2 设定文档现已按用户要求删除，原稿见 Git；当前故事以[《未竟之镇》v4](../history/v4/未竟之镇_故事与玩法_v4.md)为准，本日志保留当时实现与验证事实。

## 修改与关键决定

**Core（Unity 与 .NET 共用）**

- `Knowledge/Propositions`：命题表改为奇幻版（A 线沿用 P1—P6 的 ID；B 线改为井中灯灵 W1—W3；C 线 C1—C3），新增「主体 / 秘密主人 / 添油加醋目标 / 被什么阻止 / 指控 / 可显化 / 反驳 / 辩护」字段。
- `World/Ids`：新增旧井、钟楼两个地点和显化标志；集中提供中文显示名。内部 ID 暂不改。
- `Content/HammerEventSetup`：初始认知、关系、三人日程按 v2 设定；Session 增加关系表、日程系统、流言账本。
- `Schedule/ScheduleSystem`：出发和到达由 Core 按游戏时间判定（广场往返 3 分钟，其余 5 分钟），Unity 只负责表现；任务接管时暂停日程。
- `Rules/RumorRules`：所有认知传播的唯一入口 `Deliver`，按顺序判断：当面指控本人 → 不信任说话人 → 亲身知道的相反 → 早已知道 → 同源重复 → 已因别的源头相信 → 较真的人要证据 → 采信并纠正被反驳的旧说法。梅芙是唯一主动闲聊的人，会把「拿走」说成「偷」、把「幽光」说成「恶灵」（知道真相时不会）；布伦和芬恩只在听到指控时反驳。
- `Rules/OathBell`：钟响时，可显化说法需 ≥ 2 位居民相信（把握 ≥ 0.5），且这些人**听到过的同向说法**来自 ≥ 2 个源头；恶灵与灯灵互斥。玩家不计入。
- `Rules/HelpRules`：芬恩还锤任务按日程系统真实走到石亭、拿起、走到布伦身边交付；锤子不在时失败而不是瞬移完成。承诺、道歉、信任触发都由触发键保证只生效一次。
- `Rules/ApprenticeRules`：两人同地且一方知道对方心意时说开；布伦按「是否信谣言 / 是否亲手还锤或守信 / 是否知道借了且还了」给出拒绝、试用、正式收徒。
- `Outcome/FestivalOutcome`：7 种结局判定（不含「不被相信的信使」）、小报三条头条、流言溯源（重复闲聊合并显示）。
- `Runtime/TownRuntime`：时间改为逐分钟推进（时间日志合并为一条），对话按信任决定是否带上秘密；居民回答引用的认知按「听某人说」写进玩家手账。
- `Brain/NpcDialogue`：快照默认排除角色自己的秘密。

**关键规则取舍**

- 「借的」不反驳「偷」（借了也可能不还）；只有「已经还了」「守信」才能澄清偷窃谣言。这样布伦知道是借的，仍可能被两个独立源头说服。
- 一个人已因 A 源头相信后，再从 B 源头听到时保留原认知、只记账；誓钟统计相信者听到过的全部同向源头。最初实现只看当前认知的源头，会漏算玩家贡献，测试发现后已修正。
- 玩家把并非亲眼所见的事说成亲眼所见、或添油加醋，记为谎言。识破谎言放到第 3 周。

**Unity**

- 场景生成器：地点改名，新增旧井、钟楼（回音石板），广场长凳改为拱门形状；已用命令行重新生成场景和 NavMesh（176 三角形）。
- `NpcAgent` / `TownGame`：每帧按 Core 的目的地同步寻路，速度随时间倍率变化；头顶显示当前活动。F1 真值面板默认关闭（会剧透），增加关系和石板真值。
- `TownInteractionPanel`：重写为信使手账（选一条后对身边的人选择三种说法）、居民提问与专属行动、在钟楼读回音石板（只看数量，读到的是当时的快照）、钟响结算。仍是 IMGUI 灰盒。
- 新增 `Town.Tests.PlayMode`：进入 Play 验证芬恩按日程实际走到旅店和广场、钟响结算可用。

## 限制、风险与下一步

- 尚未经过任何真人试玩，难度和节奏都是估计；最需要验证的是玩家能否看懂「两个源头」并主动利用它。
- 规则对话的台词是模板（芬恩谈自己的心事也会说「我认为『芬恩想……』」），读起来生硬，第 3 周接模型时改善。
- 未实现：识破谎言与当面质问、带人去井边亲眼看、「不被相信的信使」结局、结局图鉴、正式 UI、次日回访。
- 梅芙每两小时和芬恩闲聊同样内容，被拒绝的重复记录已在溯源中合并，但日志仍偏多。
- 下一步：你在 Unity 里按 README 玩一局并记录卡住或看不懂的地方；然后做第 3 周的识破谎言、自由文本解析和溯源图图形化。
