## 目的与范围

上一轮自然语言“独行”三局均托付皮普，v1 `Only("pip")` 又只限制 confide，不禁止额外把契约交给梅伦。不能把旧允许名单重新解释成正向合作目标。本轮新增由调用方明确选择的 `ds-plan-constraints-v2`，同时保留 v1 和默认路径。

- 独行：不向居民 confide，不交契约原件。
- 必须梅伦：只向梅伦 confide、只允许把原件交给梅伦，实际 `ally:maren` 才算求助达成。
- 必须皮普：只向皮普 confide、不交原件，实际 `ally:pip` 才算求助达成。
- 这是本计划及其重规划的范围，不约束玩家另行输入或居民流言，不自动理解任意自由文本，不追溯撤销旧盟友。

## 关键决定

1. v2 确认时重建独立计划，针对玩家实际选中的组合重新做结构、引用、条件与归巢试运行；不以缓存缺少该组合而放行。确认前不写世界、不登记被拒请求。
2. 执行仍先完整复制步骤和集合，再检查动作限制，之后才允许移动、跨夜或耗时。确认后的草稿不能改写运行副本。
3. 完成判据同时要求实际归巢与指定盟友。Partial、confided、保管原件、摘要和预测合作均不能替代实际 ally；取回原件撤销合作后也不能冒充完成。
4. UI 保留旧四项允许名单并增加三种明确合作目标，提出时冻结，重规划不得换人或退为独行。旧 v1 字段、顺序、失败文案保持兼容。
5. 新增独立 `--plan-intent --seeds=3 [--live]`；不修改原 PlanResearch 或冻结案例。固定非新局夹具、6 次计划 / 100 循环上限，仅 Plan 可联网，无自动 HTTP 重试或模型兜底。
