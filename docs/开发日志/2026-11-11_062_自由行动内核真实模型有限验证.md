# 062 自由行动内核真实模型有限验证

## 目的与范围

承接 `e3b04d3` 的第三条 SDK 入口，用户本轮授权真实模型验证。新增独立 `--action-kernel` 研究入口，明确调用 `Session.ActAsync(input, ct, transaction)`，不是原六机制 CLI 的旧 `RunAsync(Adjudicate)`。不扩大迁移其它机制，不改规则、提示、模型、Kernel、Unity 场景或黄金。

## 关键决定

- 固定 20 个独立案例和同一世界 4 步连续行动，共最多 24 次请求。仅显式 `--live` 才由现有程序读取本机密钥并联网；默认入口及单元测试使用离线提供方。沿用 `gpt-6-luna`、研究配置、768 输出 tokens、12 KiB 请求体、单并发、无自动重试与原账本，不打印密钥或读取预算原文。
- 新 `ActionKernelResearch.cs` 在无引擎共源适配上运行真实 Kernel；手动 owner 泵只处理同步块，provider 等待与 handler 均不占 owner。每个返回原文再用旧 Session 路径执行一次，不重新联网。比较完整最终世界与 trace，仅剔除耗时和内核新增字段 `kernel_code`。
- 将意图动词 / 对象、预期效果、原始规律引用、有限私密 canary 与提交不变量分开。`committed` 不表示动作合理或目标成功；规则拒绝也可能已消耗时间。
- ready 时将私有 ReplayFrame 与独立锚分别保存，重新从磁盘读取，以真实 `Kernel.PrepareReplayAsync → Commit` 在本地字符串端口验证候选 after。锚与录制同目录，不能抵御二者一起被替换；不声称服务端来源认证。非 ready 没有回放对象，记录为未适用而非通过。
- 隐私差分只改变异地梅伦 / 雏龙位置及一条私有信念，核冻结字节与实际待发送 body 相同且不含 canary。有限字段验证不扩大为普遍安全证明。
