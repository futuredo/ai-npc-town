# 064 自由行动地点等价与拒绝分类契约

## 目的与范围

承接 `e223e21`。063的八项地点字面差异和四项操作分类差异不能直接混为错误世界动作；本轮另立 `ds-action-kernel-semantics-1`，在新采样前固定空地点等价及“可识别但不可执行”的分类责任。旧套题、生产提示、规则、内核、Unity运行时和黄金不变，不以改旧成绩代替进展。

## 关键决定

- verb / target / item 保持严格字符串匹配；place 仅空串与 before 当前地点语义等价。缺字段、null、错误类型、异地及未知地点仍失败，不将所有拒绝当通过。
- 明确重复拿取、投喂已消耗食物、重复购买仍要求识别原动作，再由真实规则拒绝；未来或明确不实施的动作、未支持能力仍用unsupported。该标准只用于新研究，未偷偷加入模型输入。
- 20独立夹具和4步同世界序列全部采用新措辞。联网前保存预注册与契约，固定单并发、gpt-6-luna、最多24请求、768输出tokens、12KiB出站体积、无自动重试。
- 延用第三入口、同原文旧路径逐字对照、真实候选回放及有限隐私差分；标准变化不会改变提交或资源规则。
