- 新增 3 项测试：14 起点类型化往返、各层显式 JSON 键序、坏扩展字段仍被拒绝且世界不变。
- `BaselinePlanner.Plan` 返回类型是源码 API 调整，全部仓内调用已迁移；未发布 SDK，不能据此承诺外部二进制兼容。
