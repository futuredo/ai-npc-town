# 玩法重设计：《传声筒》→《回音镇：誓钟响起之前》

日期：2026-11-05　分支：feature/npc-schedule-relations　关联 PR / 提交：未提交

> 历史记录：下述 v1/v2 设定已退役，文档按用户要求删除，原稿可从 Git 追溯。当前以[《未竟之镇》v4](../未竟之镇_故事与玩法_v4.md)为准；本文不作为当前需求。

## 目的与范围

用户要求先把游戏设计得好玩，再实现。原「集市前的工具失踪」偏单线跑腿：真相容易问到、玩家选择缺少代价、结局缺少重玩动力。本次只改玩法设计，不改运行代码行为。

## 修改与关键决定

- 当时新增 `玩法设计_传声筒_v1.md`（已退役）：玩家是传话的跑腿，可以如实转述、说成亲眼所见、添油加醋或保密；流言按日程碰面自行传播，阿禾会添油加醋；集市开张时用流言溯源图和命名结局收尾。
- 故事从一条线扩为三条交织的线：A 锤子（保留）、B 淋湿的布（保密托付，应做）、C 拜师（牵线，必做）。A 线的解决方式决定 C 线成败。
- 研究问题不变；「识破谎言」需要来源链，使方案 B（近期上下文）与方案 C（来源记忆）的差异能被玩家直接感受到。
- 必做范围收敛为 A + C 两条线与按钮式传话，自由文本、识破谎言和 B 线放到第 3 周。
- 编码暂停：本分支已有 `Social/RelationshipBook`、`Social/Commitment`、`NpcState` 移动字段与 `KnowledgeStore.Find`，新设计会继续使用，尚未提交、未写测试。

## 补充：同日改为奇幻版 v2

用户反馈 v1 框架仍不够吸引人，建议改为欧美奇幻小镇。当时新增 `玩法设计_回音镇_v2.md`（已退役），取代 v1：

- 核心新规则「誓钟」：日落时，被至少 2 位居民相信、且来自至少 2 个独立源头的可显化说法会变成现实；玩家是外乡信使，信念不计数，但说出的话可以成为源头。
- 研究中的「同源不叠加」与来源记忆由后台指标变为玩家必须理解的魔法条件；显化仍由规则代码统一判定，模型无权触发。
- 角色改为矮人符文铁匠布伦、旅店老板娘梅芙、半精灵跑腿芬恩（内部 ID 暂不改）；B 线由「湿布」改为「井里的灯灵」，可被信成恶灵或守护灵。
- 已动的代码：命题表加入秘密 / 主体 / 添油加醋 / 指控字段（B 线文本仍是湿布版，待按 v2 改）；对话快照默认排除角色自己的秘密；新增按游戏时间判定到达的日程系统。均未提交、未补测试。
