# M3：真实规划实验、提示适配与失败复验

日期：2026-11-09　分支：main　关联：[雏龙归巢切片计划](../雏龙归巢切片计划.md)、[完整实测报告](../归巢计划M3实测报告_2026-11-09.md)

## 目的与范围

将 M2 的多步计划、逐步执行与三类重规划接入真实模型，验证它在冻结案例、新措辞与连续世界变化中是否可用。仅计划调用 `gpt-6-luna`；居民和 GM 继续使用离线规则。

本轮交付实验及失败报告。没有修改冻结集、规则判定、离线基线，没有提高输出上限或换模型，也没有实现 M4 计划面板。

## 修改与关键决定

- **先补研究记录**：修正首个计划未计入总费用和延迟的问题；每次请求、每个完成的整局即刻落盘，取消/异常仍写汇总。保存请求前快照、实际提示和源码指纹。
- **保留截断证据**：提供方返回 `incomplete_response` 时留下部分原文、响应状态和截断原因，继续保留 usage 估算；错误仍在执行前拦截，不能确认执行。
- **一轮通用提示适配**：明确英文 ID 与 `whelp`，补充动作的前置条件、消耗和跟随含义，减少冗余移动与取舍文字。只修改 Plan 分支，不调整冻结断言或校验器来迎合结果。
- **有限失败探针**：从离线失败记录选定三类各 10 个可补救状态及 3 个死局。本地恢复完整快照，线上只送重新生成的玩家感知；每个状态只请求一次，不确认执行。
- **基线天花板如实保留**：冻结集和新措辞基线均为 100% 可执行，本轮没有把“高于基线”悄悄改成“接近基线”。可执行、满足措辞意图和最终归巢分别报告。
- **操作失误也保留**：提示曾误改到单步分支，一批实际仍用旧 Plan 提示的请求在核对后被中断；费用单列，取消请求无 usage 记未知。探针初稿曾按跨局重复的请求号接错标签，离线核对发现后修成 scope + request_id，另存 v2，初稿没有用于真实请求。

## 实际验证

| 验证层 | 结果与边界 |
| --- | --- |
| 离线回归 | `dotnet test dotnet/Town.sln --configuration Release`：208/208，不读密钥、不联网 |
| 研究工具 | Release 构建 0 warning / 0 error；有效探针 33/33 重现原始基线提案与判定 |
| Unity 主场景 | 6000.3.23f1 批处理 PlayMode `DragonsleepPresentationTests`：4/4；`.local/unity-runs/m3-final-playmode.*` |
| 冻结与新措辞 | 首轮 0/14、0/10；适配可执行 10/14、10/10，意图断言 10/14、9/10；基线可执行分别 14/14、10/10 |
| 90 局真实执行 | 三类可补救重规划 59/100、51/73、11/12；前两类低于 70%；Core 回执 90/90，无效引用被确认 0 |
| 固定探针 | 三类各 10 状态 + 3 死局，结果与整局分开，详见报告 |
| 用量费用 | 491 次请求；有 usage 部分估算 USD 0.11991332，另 2 次未知；失败与误跑均保留并记账 |

**结论：M3 实验与报告已交付，但规划验收未通过。** 完整护送 40 局模型仅 3 局归巢·余怒，离线基线 34 局，不能以接口可调用或新措辞 100% 可执行宣称可玩性已达标。

首轮与适配版结果、新措辞 h07/h08、截断、未知引用、重规划重复做法、社会取舍、逐批费用与延迟见[实测报告](../归巢计划M3实测报告_2026-11-09.md)。原始本地样本全部保留，没有合并成一个总准确率。

## 未完成项与下一步

- 模型规划验收未通过；提示说明改善了协议理解，但仍有物品/消耗误用、局部可执行却没安排团聚、失败后重复方案等问题。
- 静态试运行使用固定成功掷骰，居民未来位置也存在信息边界，不能把其可执行判定当实际可达保证。
- 固定状态探针不是模型自己走出的整局；同类状态有限，不能推论任意失败补救能力。
- UI 状态与回执一致性、可取消的规划进度、跟随/卫兵/铁笼的画面表现以及真人小测仍属于 M4/M5。
- 后续需另建未见过的实验集，明确比较模型与基线的目标达成和措辞理解增量；不覆盖本轮冻结结果。
