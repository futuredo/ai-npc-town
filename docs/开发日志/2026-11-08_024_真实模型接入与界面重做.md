# gpt-6-luna 提供方接入 + 界面改用 Medieval Kingdom UI 套件

日期：2026-11-08　分支：main（未提交）　关联：[023 第一天可玩](2026-11-08_023_第一天可玩.md)

## 目的与范围

1. 把真实模型接进《龙眠镇》的七阶段管线，与离线提供方走**完全相同**的校验与裁决，便于对比研究。
2. 用户反馈界面“丑、内容太多、不直观，没用素材包 UI 套件”——改用已购 Medieval Kingdom UI 白金皮肤，默认画面只留必要信息。

## 修改与关键决定

**真实模型（`Town.OpenAI/OpenAiDragonsleepProvider.cs`）**
- Responses API，`gpt-6-luna`，`store=false`，`reasoning.effort=none`，`max_output_tokens=384`，请求体 ≤12 KiB；单并发、无重试、不换模型；发请求前先在 `.local/openai` 账本占预算（失败也计次）；服务端错误原文不回显。
- 五类任务各有严格 JSON Schema（动词、事件、论点、造物标签全部用 enum 约束）；玩家输入以 `trust="untrusted-data"` 包裹。
- 提供方只负责收发文本，内容校验仍在 Core：模型引用他人认知、越界信任、泄密、未知规律等照样被规则拦下。
- `RoutingProvider`（Core）：按任务类型分派——默认只有玩家交互（言/行/造）走模型，夜间居民与 GM 走离线规则以节省额度；**仅在预算用尽时**降级为离线规则并在 trace 中写明“已降级”；网络/服务失败不降级、照实显示。
- Editor 菜单 `Town/Dragonsleep/AI 提供方/`：离线（默认）｜gpt-6-luna 仅玩家交互｜gpt-6-luna 全部。只有进入 Play 才读取 `.env.local`；缺密钥时自动用离线并提示。

**界面（`Town.Unity/Dragonsleep/LoomLensHud.cs`、`DsUiSkin.cs`）**
- 补导 Medieval Kingdom UI 的 567 张贴图（白金/经典皮肤、按钮、图标、26 张人物头像、纹章、背景）。
- 默认只显示：红底银框时间牌（下方菱形时间格 + 银币）、羊皮纸“当前目标”卡（只显示一项及提示）、带人物头像的对话框、右上“织言条”（七颗菱形宝石逐个点亮 = 七个阶段，一行结论）。
- 按需打开：Tab 完整织言镜（深蓝弹窗，含时间线/上下文/原始返回/校验/掷骰/世界改动）、J 日志、M 地图（快速前往与结束时段）。开场、日终、结局用羊皮纸弹窗与红色按钮。
- 头像映射：奥斯里克=灰须皮裘贵族、梅伦=兜帽女子、玛尔妲=村妇、维丝娜=绿兜帽红发女子、皮普=少年、言契师=村夫。字体优先宋体（本机系统字体动态生成）。
