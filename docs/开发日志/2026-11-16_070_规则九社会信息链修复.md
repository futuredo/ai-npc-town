# 070 规则九社会信息链修复

日期：2026-11-16　分支：`main`　提交：随本轮 rules-9 收尾提交

## 目的与范围

修复 rules-8 诊断中发现的两个社会信息链问题：二跳认知被静默丢弃但回执仍像成功，以及交付、取回、出示和本地岗哨等实际规则事件没有进入目击居民本人认知。规则版本升级为 `dragonsleep-rules-9`，普通自由对话仍不把自然语言自动当作事实记忆。

本轮不修改 `PlanCases.cs`、旧黄金原件、旧真实分数、商业素材、玩家存档、预算账本或其他任务草稿；任务二 `missing_output` 可观测性诊断尚未开始。

## 修改与关键决定

- `DsBelief` 增加 `RootId`、`RootOwner`、`Hops`，并进入快照、Hash、Diff、回放和居民本人感知；旧快照按 ID 兼容补全。
- 采用最多两跳的显式社会链：亲历 → 一跳转述 → 二跳转述；第三跳、回传、重复根认知和转述他人私有认知均有明确拒绝原因码。Partial 只呈现实际传出的内容。
- 成功候选规则效果生成事件认知，Commit 才生效；当前同地点居民作为在场目击者。覆盖真实 `give` / `take` / `show`、原件保管建立/撤销、重复出示和居民本人所在地点的本地岗哨观察。
- 每个居民、每个事件主题最多保留最近 2 条；事件和传播认知共用上限。居民请求保留原有字符串 `your_beliefs` 形状，另提供来源摘要，不修改旧提示版本和旧提示正文。
- 新建 `Golden/rules-9`，rules-6/7/8 原始工件字节保留，跨规则版本严格回放拒绝。研究器新增独立预注册套题 `ds-social-chain-rules9-1`，不改旧四机制题目或历史分数。
