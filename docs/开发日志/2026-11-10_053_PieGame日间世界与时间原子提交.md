# 053：PieGame 日间世界与时间原子提交

日期：2026-11-10。第二条真实 SDK 接缝，与本轮 v2 合作主线分别提交；不迁移夜间、模型、造物或整个计划执行器。

## 目的、范围与决定

只放开 phase_start 会让 SDK 拒绝后时钟已经推进，不能兑现原子性。本轮新增 `IDsDayPhaseTransaction / DsDayPhaseWrite`，将清晨→正午、正午→黄昏的候选世界及 Session spent 纳入同一个同步 compare/write。候选先在副本执行一次 Advance / PhaseStart，真正写入之前 live 状态和时间预算完全不变。

`DsSceneRuleTransaction` 同时承载两个明确 scope：原 enter 零耗时移动、日间世界＋spent；都有主线程、精确 JSON / digest、单次受控写入、成功状态一致性和 finally 撤能力。没有第二份影子世界或 SDK 成功后 executor 再补写。Game 只分流日间按钮，黄昏 / 深夜仍走旧 RunNight；Kernel 和通用 Unity 桥源码不变。
