# 世界观改为《未竟之镇》

日期：2026-11-05　分支：feature/npc-schedule-relations　关联 PR / 提交：未提交

## 目的与范围

用户认为 v3 初稿的世界观（回音之誓、过路人的信）不够新奇。我提出三个方向：A 没写完的书、B 说出口的话变成鸟、C 湖中倒影镇。用户选了 A。本次只改设计文档和素材需求，不改代码和规则。

## 修改与关键决定

- 设计文档改名为 [未竟之镇_完整设计与后续计划_v3](../history/v3/未竟之镇_完整设计与后续计划_v3.md)，重写了世界观、人物、剧情文案、结局名称和计划：
  - 小镇是一本作者停笔在第七章的书。每天黄昏墨钟敲响，角色共同相信的事被写成正文。现有的显化规则原样对应「落墨三规」：一人之信不落墨、一人之言不落墨、读者之信不落墨。
  - 玩家是从书页外掉进来的读者，口袋里有作者撕下的最后一页，取代过路人的信。最后一页按结局倾向有四种结尾。
  - 视觉语言即规则：没人相信的是铅笔稿，有人相信时线条加深，落墨后上色。玩家的谎言是红墨水，被识破时才浮现，取代「信使不可信」的抽象表现。R1 改为「那个读者在改写我们」。
  - 人物重新解释：布伦是作者写得最细的人，所以最固执；梅芙身上漏进了叙述者的声音，所以爱添油加醋；芬恩是只写了一半的人，拜师成功即被写完整，偷锤谣言落墨则被写成贼。守钟人由奥丁改名为霍勒斯，仍不计入墨钟。灯灵改为作者划掉的一段文字；「被划掉的是作者自己」作为可做的谜底。
  - 9 个结局改为「第七章的标题」，图鉴做成书的目录。
  - 计划：W1 新增文案替换和「草稿 / 墨线 / 上色」着色器原型；W2 新增世界线稿随相信人数加深；W3 新增落墨演出。草稿与上色的基本表现列为不可砍。
- 新增 [素材清单_未竟之镇_v3](../history/v3/素材清单_未竟之镇_v3.md)，旧 v2 清单标注已被取代：
  - 美术风格由统一着色器决定，模型只需要形状对，灰盒加着色器即可演示。
  - 道具、地面、动画需求减少；新增着色器、纸纹、排线纹理、墨水系特效、手写中文字体和书写音效。
- `art/asset-manifest.json`：
  - 同步改写条目名称、数量和备注。
  - 新增 `shader_sketch_ink`、`tex_paper_hatching` 两个 planned 条目。
  - 全部仍未导入。
- README、旧排期文档、素材交付规格和 004 日志的链接与说明同步更新。
