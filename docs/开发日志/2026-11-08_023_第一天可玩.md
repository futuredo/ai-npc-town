# 龙眠镇第一天可玩

日期：2026-11-08　分支：main（未提交）　关联：[022 龙眠镇重置](2026-11-08_022_龙眠镇重置.md)

## 目的与范围

在 022 的管线与场景基础上，让第一天成为一段有目标、有引导、有风险、有收尾的完整体验：开场 → 打听 → 购买 → 说服 → 引出雏龙 → 藏好 → 夜间居民自主行动 → 日终总结。

## 修改与关键决定

**Core（`Town.Core/Dragonsleep`）**
- 新动词 `buy`：物件带 `price:N` 标签才可买，银币进世界状态；店主对你信任很低时价格翻倍。感知里新增 `coins`、`for_sale`。
- 时间改为每时段 4 点预算：【言】1 点，【行】/【造】2 点；做不到的事（未进入掷骰的驳回）不耗时，真实尝试的失败要耗时。原“每 3 句话推进一时段”使黄金路径在藏好雏龙前就入夜。
- `DsObjectives`：第一天五个必做目标 + 一个可选目标，完成判定只读世界状态（与提供方无关）；每个目标附带提示；黄昏雏龙暴露时给出预警；日终总结（完成/未完成/夜间各居民行动/雏龙现状/当天 AI 调用与规则修正数）。
- 泄密拦截改写：拦下秘密时保留本来允许说的线索（之前皮普每次都整句被换成“我什么都不知道”，连“小烬爱吃熏鱼”也被吞掉）。
- 平衡：雏龙信任玩家后，喂、引、藏的难度按信任降低（最多 −0.30）；暴露在外的雏龙夜间被搜到的基础概率 0.55→0.45；玩家亲手藏好的再 −0.15。
- 开局站位与场景一致：奥斯里克第一天在集市。

**Unity**
- 开场卡（世界观 + 操作说明）、左侧目标与下一步提示、时间预算显示、居民头顶名牌（最近者显示“Enter 交谈”）、黄昏红色预警条、日终总结卡、结局卡复用同一模态层；模态打开时禁止移动与结束时段。
- Enter：身边有人自动切到【言】，没人自动切到【行】（在工坊切【造】）；【言】身边无人时提示并切换，而不是静默失败。
- 输入焦点判断改为包含 TextField 内部元素。
- 梅伦修女站位：教堂广场是抬高平台（y≈25.5，地形 17.4），改为手工高度，已截图确认站在广场上。

## 限制、风险与下一步

- 实玩由脚本驱动（瞬移 + 直接提交文本），**没有真人用键鼠完整走一遍**；步行距离（集市→码头约 300 米）靠“快速前往”缓解，节奏未经真人检验。
- 离线提供方是关键词规则，玩家换种说法可能不被理解；真实模型接入后才能检验开放输入。
- 第一天抓走雏龙后，第二天还没有“追回”路线（会直接走向“远洋”结局）。
- 第二、三天的目标、墓穴契约页、工坊造物引导尚未做。
- 下一步：真人试玩第一天并记录卡点；接入 gpt-6-luna 提供方（授权后小样本对比）；第二天内容。
