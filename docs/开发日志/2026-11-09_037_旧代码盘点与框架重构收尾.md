## 关键发现与决定

1. 旧 `TownRuntime` 的灰盒和月光切片各有场景与回归入口，不能仅按当前主玩法未使用就删除。场景扫描未命中的脚本也有动态 `AddComponent` 或升级兼容引用。
2. 现行龙眠镇领域代码未发现对旧领域类型的直接依赖，但 `OpenAiDragonsleepProvider` / `OpenAiPolicy` 仍使用旧 `Brain.TokenUsage`，场景生成器仍引用月光主题文件。隔离旧程序集前要先明确这些边的归属。
3. 旧 `TownSave`、月光录制、龙眠镇回放是三种独立协议，不自动互转。保留 GUID 也不能单独证明程序集迁移后的序列化兼容。
4. 本轮保持方案 C；A / B 必须由用户另行确认，先补旧场景加载与旧档读回证据。未来涉及旧代码移动时，要运行各旧 PlayMode 组，不能以本轮龙眠镇四项测试替代。
5. SDK 与数据化均未实施，也未授权付费验证、安装新依赖或包发布。
