# 034 规则与界面机械拆分

## 目的与范围

框架重构阶段 2：降低规则与 HUD 的单文件阅读成本，不改玩法、数值、提示词或序列化协议。

## 修改与决定

- `DsRules` 保留原文件及 `.meta`，以静态 partial 拆为 Core、Dialogue、Effects、Social、Director、Craft、Travel。公共前置与掷骰在 Core，行动后果在 Effects。
- `LoomLensHud` 保留原 MonoBehaviour 文件、类名、字段和 `.meta`；提取 Dialogue、Lens、Journal、Style，原有 ArtDirection 保留。当前没有独立计划面板，本轮不新增 M4 界面。
- 新增 11 个 partial 文件均附新 GUID 的 `.meta`。未改场景、预制体或序列化字段。
- 新增基础 `.editorconfig`（UTF-8、LF、4 空格、建议 160 列）。只清理当前 Core/Dragonsleep、Unity/Dragonsleep 两目录的超长行，均为 0；不全仓格式化旧代代码。
- 提示词仅在源码中拆为字符串拼接，实际字节不变。研究 source-manifest 补列拆出的规则文件，避免空壳文件哈希冒充完整规则证据。
