# 旧原型退役与工程整理

日期：2026-11-09　分支：main

## 目的与范围

用户在结构审查后明确授权：“你把你认为的要删的都删掉吧，之前的那些个验证确实没什么用了”，并要求按优先级整理。本轮因此执行旧原型退役，不再停留在待确认方案，也不为了删除它们重做旧玩法验收或创建归档 tag。

保留当前《龙眠镇》v6、`Town.Research`、现行测试及独立 PieGame 内核验证。整理前源码可从 Git 提交 `2747b47` 查询；这是历史快照，不表示本轮重新验收了旧玩法，也不能恢复被 Git 忽略的商业资源。

## 修改与关键决定

### 1. 统一当前入口与文档

- README、项目进度和工程骨架统一指向龙眠镇；明确 M3 尚未通过，M4 由另一会话开发、单独验收。
- 15 份 v3 / v4 / v5、月光及删除前盘点文档进入 `docs/history/`，另保留旧进度和首次 OpenAI 验证快照；修复迁移链接。历史日志只机械修链接，不改写原有决定或测试数字。
- OpenAI 规范改为现行入口，移除已不存在的 Smoke / 灰盒菜单操作；标准对话和已授权研究配置仍严格分开，模型、价格、预算及密钥边界未改变。
- 资源清单把旧月光绑定明确标为历史快照，素材总台账追加派生资产退役与共享主题迁移记录，保留来源、许可未知项及原验收事实。

### 2. 删除完整旧闭环，不切断共享依赖

- Core 删除旧 Actions、Brain、Content、Knowledge、Logging、Memory、Moonlight、Outcome、Rules、Runtime、Schedule、Social、Tasks、World 的 33 个 C# 文件及原元数据。
- 删除旧 `OpenAiDialogueClient`、`Town.Sandbox`、`Town.OpenAI.Smoke`，从 solution 精确移除两个旧 CLI；solution 现有六个工程。
- 删除旧 Unity 根目录 8 个运行脚本、Moonlight 9 个运行脚本、6 个旧 Editor 工具、旧灰盒 / 工坊场景及自制材料与导航，删除本机 Gameplay 中列明的月光派生场景及其导航 / PanelSettings。没有删除厂商原场景、Prefab、贴图或素材源包。
- 删除 10 个旧 .NET 测试文件（115 项）和 5 个旧 PlayMode 测试文件（19 项）；它们不再是现行回归负担。
- 去掉费用接口对旧 `Brain.TokenUsage` 的兼容重载，保留 5 组整数费用断言；在现行 provider 测试中补回“合法响应缺 usage，费用未知且不重试”的覆盖，不为旧类型保留无用 API。

共享主题从 `Town.Unity/Moonlight/MoonRuntimeTheme.tss` 移至 `Town.Unity/Shared/UiTheme/`，原文件与 `.meta` 字节不变，GUID 仍为 `f248bbac75c5a4c5d97c3993e160af62`。生成器更新路径，现有龙眠镇 PanelSettings 不改。Build Settings 只保留龙眠镇场景。通用 `SceneSnapshot` 改为读取龙眠镇，不再引用已删除的灰盒生成器；本轮没有重建主场景。

### 3. 有限清理本地产物

精确预览后清理旧 `.local/3c-rebuild-20261108`、`.local/skeleton/compile`、旧 3C 临时文件、Python 缓存和根目录旧 Unity 日志 / 测试报告，共 478 个文件、78,254,640 字节（约 74.6 MiB）。这不是清空 `.local/`：当前研究 / 回放证据、预算账本、密钥、玩家历史存档、商业素材及 Unity Library 均保留。

### 4. 并行会话隔离

另一会话独占 M4 的 Game / HUD partial 和新增计划 UI 测试。本轮未编辑、暂存或提交这些文件。对方暂停 Assets 写入后，本轮执行一次统一验证；结束后将 Unity 窗口交还对方修复和验证 M4。以下 4 项既有表现测试只证明交接时清理快照的回归，不代表 M4 完整验收或其后修改已验证。

## 限制、风险与下一步

- 这是退役与结构整理，不是新功能交付；没有重新运行旧玩法、真实模型研究、真人手感、美术或设备性能验收，也未构建发行包。Build Settings 正确不等于已证明发行包可发布。
- 当前场景和商业资源在被忽略的 `LocalThirdParty/`，新机器检出仍需合法恢复素材；来源与许可没有因技术回归而自动批准。
- 不清除旧玩家存档，也不把旧格式自动迁移到龙眠镇；历史临时验证目录已删，不再保证旧日志引用的每个临时文件仍可读取。
- 龙眠镇与 PieGame 独立内核尚未接线，内容数据驱动也仅有设计；本轮不借整理实施 SDK 迁移或改规则 / 模型输入。
- 下一步由 M4 会话完成其计划 UI 的专项回归，再继续处理 M3 已记录的社会补救与否定约束问题。当前主文档可随其实际验收更新，不能提前写已完成。
