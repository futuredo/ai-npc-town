# 工程骨架说明

日期：2026-11-04。本轮目标是可继续扩展、可离线验证的纵向主流程，不代表完整月度 Demo 已完成。

## 入口和依赖

```text
Unity TownGame + TownInteractionPanel      dotnet/Town.Sandbox
                  \                         /
                    Town.Core/Runtime/TownRuntime
                    ├─ World + Knowledge：世界事实与各人认知
                    ├─ Brain：ILLMClient、规则回复、结构校验、请求防过期
                    ├─ Rules：交互前置条件、线索与归还、集市截止
                    ├─ Tasks：维修任务生命周期
                    ├─ Memory：按 NPC 隔离的近期对话记录
                    └─ Logging：每局最多 256 条审计事件

Town.OpenAI → Town.Core：显式验证入口独立存在，不被 Town.Unity 引用
```

`Town.Core` 源码只保留在 Unity Assets 下，由 .NET csproj 链接复用。日常 Play 与 Sandbox 都使用 `RuleDialogueClient`，不读密钥、不创建网络客户端。`TownRuntime` 支持注入 `ILLMClient` 便于测试；将来接实时模型必须另外接入成本闸门，不能直接把默认客户端替换成无预算实现。

## 当前已经连接的流程

1. 点地面走近居民；导航适配器根据实际位置回报地点，点击目标不算已经到达。
2. 操作面板选择固定话题，规则客户端只从该 NPC 的认知快照取回复。不认识的话题返回未知，不解析自由文本，也不执行模型动作。
3. 雨棚查看线索 → 拾取锤子 → 走回阿木身边 → 出示线索 / 归还锤子。
4. 阿木在广场收到锤子后开始维修，60 游戏分钟完成；18:00 截止，未完成时进入临时座位结局状态。
5. 认知变化保留来源与纠错历史；对话记录按角色隔离；世界修改与交互结果进入审计日志。
6. F5 重开会销毁旧运行时、取消旧对话、重置玩家位置与任务；旧回复不得写入新局。

当前的「修好 / 临时座位」是规则状态和面板文字，尚无正式模型状态替换、维修动画或收尾演出。NPC 日程仍固定，玩家为唯一运输者。

## 验证与运行

在仓库根目录执行（默认均不调用付费 API）：

```bash
dotnet test dotnet/Town.sln --configuration Release
dotnet run --project dotnet/Town.Sandbox --configuration Release
```

首次还原 NuGet 包需要开发环境具备依赖缓存或网络；测试本身不依赖网络、密钥或模型服务。已还原环境可使用 `--no-restore`。

Unity 打开 `Assets/Scenes/Town_Graybox.unity` 后 Play。现有 TownGame 自动附加灰盒操作面板，无需重新生成场景。右侧是离线交互，左侧 F1 是开发者真值面板。点击面板会屏蔽点地移动；对话等待和 F2 暂停会停止玩家导航。开发按钮可推进 60 游戏分钟、导出本局日志。导出路径是 `Application.persistentDataPath/town-session-log.txt`，它是调试文本，不是存档。

## 后续接口位置

| 下一项 | 接入位置 | 最小验收 |
| --- | --- | --- |
| 正式对话 / 记事本 UI | 替换 `TownInteractionPanel`，继续调用 Runtime | 关闭、重开、等待、输入焦点与点击不串扰 |
| 角色卡和事件配置 | `Town.Content/Config` → Content 工厂 | 编辑器配置导出与无画面测试初始状态一致 |
| 日程与搬运任务 | `Tasks` + Unity 导航到达 / 失败回报 | 实际到达才交接，超时可恢复，无瞬移完成 |
| NPC 闲聊与传播 | `Rules` → `KnowledgeStore.Learn` | 只给实际接收者写入；同源去重、纠错有来源 |
| 关系与承诺 | 新增规则与结构化状态 | 戒备影响协助，截止判定只执行一次 |
| B/C 记忆检索 | `Memory` + 请求快照构造 | 当前角色隔离，同一模型与输入预算对照 |
| 单槽快照与回放 | 独立 Persistence 适配层 | 完整保存时间、事实、认知、任务、关系与序号；恢复后局代际递增 |
| 模型游戏内入口 | `ILLMClient` 注入 + 已有预算守卫 | 显式授权、取消 / 超时 / 预算耗尽、旧回包测试 |
| 实验 Runner | `dotnet` 新工程，复用 Runtime | 默认离线；付费批量运行另做估算与授权 |

避免提前建一套空泛通用任务框架；目前用完整的维修任务做样板。动作注册表里的 7 个动作仍是定义，并未全部落地。没有把存档、回放、配置热加载或 B/C 实验标成已实现。

## 已知边界

- 当前 `WorldState` 与 Belief 仍是原型可变对象，靠规则接口和测试维持边界，尚未形成编译期隔离。
- 当前地点是 3 米范围的离散交互区域，正式美术导入后需重新检查距离、遮挡和 NavMesh。
- P4 是初始历史位置命题，旧知情者不会因玩家拿走锤子自动获知新位置；动态位置的目击、时效与纠正仍待实现。出示线索现在只纠正 P3，不写入已经过时的位置。
- C1 仅证明锤子曾归还；尚未实现 C2 证词、P5 传言澄清、关系变化和次日回访。
- 审计日志有界，会淘汰旧条目；近期记忆每人 20 轮，未进入模型提示。它们不能用于声称完成确定性回放或长期记忆实验。
- 本轮无 Unity MCP 实例可连接，需补实际资源导入、Play、点击与寻路验收；程序集编译不能替代这些验收。
