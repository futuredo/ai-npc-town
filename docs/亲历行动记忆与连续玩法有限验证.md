# 亲历行动记忆与连续玩法有限验证

日期：2026-11-12。研究套件：`ds-action-experience-memory-1`。本报告只读核对既有产物，不重跑、不重抽、不覆盖旧结果。

## 结论先行：记住“刚才那一份”有用，但不等于理解整段玩法

- 两个独立真实请求批合计 **96 次**，不是同一 manifest 下完整通过的 96 次。正式不变量成绩分别为 **首批 31/32、续批 64/64**。
- 逐步严格意图匹配为 v1 **31/48**、v2 **41/48**；实际形成的第二步重复挑战为 v1 **3/11**、v2 **10/12**。这是有限样本观察，不是普遍正确率或统计显著性结论。
- 记忆臂在鱼已吃掉、契约已交走后，更常保留原物件 ID，让规则给出具体拒绝，而不是丢掉指代或改成 unsupported。**拒绝正确可以是玩法成功；安全拒绝却不必然是意图理解成功。**
- 连续链也暴露反例：模型把“先观察”提前执行为搜索，或把“只观察／等候”误判为不行动。目标最终达成会掩盖这些失误，不能用最终目标替代逐步验收。
- 这里只覆盖四类预置中途状态、三个固定世界种子、每臂四步开放行动；不是完整归巢、真人试玩、M3 整体验证或自主规划证明。

## 首批停止：研究比较器误报，但模型错误必须保留

A 第 32 次原始输出为：

```json
{"verb":"confide","target":"maren","item":"whelp","place":"","laws":[],"difficulty":0.2,"narration":"你现在向梅伦修女托付护送小烬的打算，请她帮忙。"}
```

`whelp` 是雏龙目标 ID，不是物件；`issues=["不存在的物件：whelp"]`、`failure=unknown_entity`，意图匹配仍为 false。旧执行路径 reason 是“`不存在的物件：whelp`”，Kernel 按既有映射展示“`行动未通过结构或规则校验，未提交。`”；旧 receipt status 为 `unknown_entity`，Kernel 为 `host_rejected`。旧研究器逐字比较展示 reason/status，因此误报规则不变量并停止。

本步产品世界未变：before=after=`21fad665c829cf04369130cff393269beac5917ded1457ee15a339505f323bcc`，版本 2→2，roll=null，time=0，effects/changes 为空，契约仍归 maren、未形成 `ally:maren`。这是**研究比较器适配缺陷与模型错误并存**，不是让模型错误变正确。

续批前仅研究器 `MemoryRulesMatch` 适配此映射：先核完整 Failure、Rejected、Kernel 固定文案、原执行器评估 reason／reason code／notes、ValidationIssues、roll／difficulty、零耗时零变化，再仅归一 receipt status 后严格比较其余回执；候选世界仍要求完全一致。产品规则与映射未改。B 同类错误出现两次，正式不变量通过但意图、目标仍失败。

本文没有重跑旧 32 次、没有给旧 summary 补“通过”，也不把只读状态审计写成同 manifest 的“96/96 全过”。

## 记忆与隐私的实际边界

`DsPlayerActionMemory` 仅从冻结玩家可见感知和执行器评估的受限物权变化形成记录，不扫描世界私密真值、完整 trace／effects，也不采集玩家文字或模型 narration。记录字段为 `request_id,at,verb,target,item,item_name,result,item_outcome`，最多最近 **4 条 FIFO**；历史目标不证明当前在场，历史物件不证明当前持有／仍可用。

实发 v2 prompt 的历史数为 0、1、2、3；第二步确有 `consumed_by_this_action`、`handed_over_by_this_action`、`acquired_by_this_action`，照明为 `no_transfer_observed`，不是虚构“当前拥有”。本轮每链四步，**没有真实模型覆盖第五条入队后的 FIFO 淘汰**，也没有验证长期遗忘后的玩法。

96 份 outbound 感知未携带完整 actors／beliefs／world snapshot；本地 before/after 私有世界只用于审计，未作为请求正文。两份 `privacy-difference.json` 均为 frozen/outbound 字节相等，但只是同一组异地梅伦位置、雏龙位置、私有信念的有限差分；检查函数调用的是默认 v1 感知，**不应当作 v2 任意历史或通用隐私证明**。

## 下一步与本报告冻结

继续集成核心玩法时，优先验证“玩家当下尝试→具体规则后果→下一步仍承认已发生历史”：保留同物件指代的收益，同时解决观察／等待被否定词吞掉、未授权搜索、confide 对象槽位混淆。扩展到移动、跨时段和更长历史时，应重新冻结新案例、保留失败与分叉，不用本轮最终目标充当完整玩法通过。

本报告新增后冻结；旧 summary、逐步原文、manifest 全部保留。本次仅做读取、JSON／哈希计算和新增本文，未运行 Unity、dotnet、API、Git，也未读写密钥／环境文件或预算账本；测试结果由主会话开发日志另行汇总。
