## 当天执行顺序

1. **确认包与授权**：只用上表新包；摘要须 `result=Succeeded`、`buildResult=Succeeded`、错误 0 且构建退出 0；冒烟与短局 JSON 均 `passed=true`、进程退出 0。保留警告，不把“有警告但可构建”改成视觉验收。
2. **本机而非分发**：包含商业素材，本轮安排参与者在有素材授权的本机操作；不上传仓库、群文件或公开链接，不把招募扩为再分发许可。
3. **建匿名记录**：给每人编号 `M5-P01`、`M5-P02`；复制空白记录表到不入 Git 的本地记录目录（建议 `.local/m5-human/<日期-场次>/`，目录名不含姓名）。检查没有旧 Player 并行运行；退出自动化验证后的 Player，但不要清理历史存档或证据。
4. **隐私同意**：按脚本分别确认参与 / 文字笔记 / 截图 / 录屏 / 录音，默认不录制；记录用途、保管人、访问范围和删除日期。未明确同意的项目不启动；拒绝录制仍可参与。
5. **准备干净开场**：从 Finder 打开新 `.app`，或在终端执行下方命令。普通启动不加任何 `--dragonsleep-smoke`、`--dragonsleep-journey*` 参数，不选在线提供方，不放入密钥。首次可交互前单独计启动耗时；确认开场页后读任务，再开始 5 分钟计时。
6. **5 分钟自由短局**：主持人只读指定话术；观察者按事件记录，不提醒 P 或路线。5 分钟即停，不为补齐场景延长、不重开刷结果。没有遇到的抓捕、跨夜、取消、结局等记“未遇到”。
7. **先冻结，后访谈**：保存原始 5 分钟记录，再做 7 个开放问题。补充演示若确有需要，只能放在访谈之后、由用户另行决定，标为“辅助观察”，不混入自主发现或理解结果。
8. **结束与汇总**：退出 Player，按同意范围保管原始资料；仅将去标识化问题汇总交项目负责人。主持人填汇总模板，GM 决策由用户签字 / 留日期，不由自动化代判。

## 本轮不做

- 不模拟参与者、不填写虚构的成功率 / 访谈引语，不用自动化短局当真人记录。
- 不改 Unity 代码、玩法、规则、提示、资源或门槛，不联网，不增加重试。
- 不加埋点：人工秒表、事件笔记和可选的经同意录制已经能支持这轮发现性观察。若确需计划打开 / 确认 / 取消 / 等待时长埋点，先列最小事件字段、匿名化和保存期限，等待用户批准再另立实现任务。
- 离线等待只能说明本机离线反馈；不能代表真实 API 延迟、费用或线上取消体验。

真人人数、时间、录制同意、保管 / 删除方案、是否扩测，以及最终 GM 推进决定均留给用户确认。无真实模型 usage，费用估算写“未知（本轮未调用真实模型）”，不要写成已验证账单为零。
