# 赛后访谈（7 题，主持人用）

**真人尚未执行，以下只有问题，没有参与者答案。** 5 分钟停表并冻结观察记录后再问；访谈不计入自由短局。只记录匿名编号、问题号、去隐私原话和必要时间。参与者可跳题，不要求给“正确答案”。

主持人开场：“谢谢，接下来想了解你刚才的想法。没有标准答案，不记得或没遇到也可以直接说。”先听完整回答，再用“能讲讲当时哪一步吗？”或“你是根据画面上的什么这样判断的？”追问。不表扬正确机制、不纠错，不问“你是不是觉得……”。

1. **Q1｜目标与当下判断**：刚才你觉得自己要做什么？停下来时，你认为事情进行到哪了？哪些画面或文字让你这样判断？
2. **Q2｜第一次找路**：一开始你是怎么决定先做什么的？你注意到了哪些入口，哪些地方后来才发现，或到现在也不知道有什么用？
3. **Q3｜计划与发生的区别**：如果你打开过计划，能从第一次看到它讲起，说说你当时认为哪些事情已经发生、哪些还没发生，以及你接下来为什么那样操作吗？**若未打开**，问“你刚才是怎样安排下一步的？有什么想做但没找到办法的事？”不要现场教 P 后再记为自主发现。
4. **Q4｜意外与恢复**：有没有结果与你预期不同的时候？当时你怎么理解发生了什么、接下来做了什么？**若没有自然出现**，问“有没有让你不确定是否生效的操作？”没有就记未遇到，不编造失败假设来考“再确认”。
5. **Q5｜看见的状态与现场**：你怎么判断小雏龙和其他角色当时的状态、位置或关系？有没有让你看错、找不到，或看到了仍说不清的时刻？如果到过结局或重开，能说说前后你看到的变化吗？未到过则不追问该结局细节。
6. **Q6｜等待、取消与重复**：回想刚才节奏，哪些时候你在等、在犹豫，或又做了一次同样的操作？你当时在等什么反馈，怎么决定继续、取消或换一种做法？离线回复太快、没有等候也如实记录。
7. **Q7｜保留与优先改动**：如果还要再玩一会，你最想继续做什么？有哪些东西希望保留，哪一处最希望先改变？为什么？

## 记录和结束

每题记录“原话 / 关联观察事件 ID / 主持追问原话 / 跳过或未遇到”。解释性推断单列，不把“他说懂了”改写成行为已证实；草稿、再确认理解与观察表 C 对照，冲突并列。

最后说：“谢谢，这些记录会帮助我们决定下一步优先改哪里。如果你想撤回资料，可通过刚才约定的渠道提供你的匿名编号。”确认录制已结束。若参与者主动询问机制，可在访谈结束之后解释；解释时间和内容另记，不补写成访谈前已理解。
