- 删除旧 Core 14 目录、旧 Unity / Editor 入口、旧场景及其专属 .NET / PlayMode 测试；不再维持旧玩法可运行。

- 不清除当前实验证据、密钥、预算账本、玩家历史存档或商业源包。实际验证与本地输出清理明细见 [043 整理日志](开发日志/2026-11-09_043_旧原型退役与工程整理.md)。
