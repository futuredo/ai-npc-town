# OpenAI 接入与成本规范

更新：2026 年 11 月 4 日。

## 当前决定

用户授权使用 OpenAI Developers 中的 API 额度验证小镇，优先低成本模型，先少量调用。已通过安全设置流程创建用户选定的 `Codex` 密钥，目标为 `Personal / Default project`，创建时选择有效期 100 天。密钥保存于仓库根目录 `.env.local`，不进入版本控制。

截图曾显示 USD 200 赠送额度；它是当时的界面快照，不作为实时余额，也不是本项目的支出预算。实际组织归属、额度到期与扣费明细以 OpenAI 平台为准。

## 模型与费用

本轮固定使用 **`gpt-6-luna`**，通过 Responses API 请求结构化 JSON，`reasoning.effort=none`，`service_tier=default`。官方将它定位为高频、成本敏感任务模型，支持结构化输出。[官方模型说明](https://developers.openai.com/api/docs/models/gpt-6-luna)

2026-11-04 核对的 Standard 短上下文价格：每百万 token，输入 USD 0.10、缓存输入 USD 0.01、输出 USD 0.50。按一次 2,000 输入 + 200 输出、无缓存计算，约 USD 0.0003；1,000 次约 USD 0.30。这只是固定用量下的估算，不包含价格变化或额外工具服务。[官方价格表](https://developers.openai.com/api/docs/pricing)

常规询问、角色短回应和有限意图判断先使用低价模型。若质量不足，先记录失败样本、改善上下文和规则；更强模型只在提出对比用例与预算后显式启用。禁止请求失败时自动切换高价模型。

## 可执行的限额

参数集中在 `unity/Assets/Town.OpenAI/OpenAiPolicy.cs`：

| 项目 | 当前限制 |
| --- | --- |
| 单轮真实请求 | 最多 3 次 |
| 工作区当日真实请求 | 最多 20 次，UTC 日期，跨进程累计 |
| 单次输出 | 最多 384 tokens |
| 单次输入 | 完整请求 JSON UTF-8 大小最多 12 KiB；玩家输入最多 500 字符、认知最多 24 条 |
| 推理 | `none`，减少此类短对话的额外推理开销 |
| 并发 | 每个 client 1；重复点击立即返回 busy，不排队 |
| 超时 | 连通性测试 30 秒；游戏交互延迟另行实测优化 |
| 自动重试 | 0；401、429、5xx、超时都停止，不换模型 |
| 费用预留 | 每次 USD 0.002；单轮上限 USD 0.01、当日 USD 0.05 |
| 额外工具 | 不启用搜索、文件、图像、语音等工具 |

费用预留按当前文本价格、输入大小和输出上限留有余量，用来在发起前阻断请求；它不是平台计费的硬保证。3 次最多预留 USD 0.006；每天 20 次最多预留 USD 0.04，请求数上限会先于金额上限生效。真实用量另从响应的 `usage` 计算；失败缺少 usage 时仍保留预留，费用标记未知。

预算账本存于 `.local/openai/budget-YYYY-MM-DD.json`，发请求前加锁写入。超时、取消途中或服务失败也占一次，防止反复重试。不得靠删除账本绕过限制。该限制只覆盖使用本入口、同一工作区的进程，不是 OpenAI 组织级或跨设备限额。

## 密钥与配置

- `.env.local` 已忽略，文件权限限制为当前用户读写；不要用 `cat .env.local` 或其他会打印密钥的命令检查它。
- 本项目文件中的密钥优先于进程环境变量；文件缺少值时才读取 `OPENAI_API_KEY` 环境变量，避免意外使用其他工程的额度。
- `.env.example` 仅保留空变量。密钥不进入 C#、ScriptableObject、场景、Prefab、截图、日志或 GitHub Secrets。
- 本轮 endpoint 固定为 `https://api.openai.com/v1/responses`，禁止通过环境变量把密钥转发给第三方代理；禁用 HTTP 自动重定向。
- `store=false` 请求不创建可继续引用的应用响应状态；这不等于承诺平台零保留，平台数据政策另行适用。
- 发行给其他玩家之前，必须将密钥和费用控制移到受控服务端；当前仅是本机开发验证入口。

## 如何测试

在仓库根目录执行：

```bash
# 离线单元测试：模拟 HTTP，不读取真实密钥，不消耗额度
dotnet test dotnet/Town.sln --configuration Release

# 默认离线预览：列出模型和本轮上限，不读取密钥、不发送请求
dotnet run --project dotnet/Town.OpenAI.Smoke --configuration Release

# 用户授权的真实验证：最多三次，首次失败即停止
dotnet run --project dotnet/Town.OpenAI.Smoke --configuration Release -- --live
```

真实验证使用 `HammerEventSetup` 初始化的认知：阿禾被问工具位置，小川被问位置与来源，阿木被问是否偷窃。它复用 `Town.Core` 和 `Town.OpenAI` 的 C# 源码，而不是额外维护一套 Python 模拟逻辑。

Unity 重新导入脚本后，菜单 `Town / AI / 测试阿禾认知（1次付费请求）` 提供一次显式调用。它创建独立的验证快照，结果进入 Console，不修改当前游戏场景；与 CLI 共用同一账本。打开工程或进入 Play 不会自动调用。

CLI 结果位于 `.local/openai/smoke-*.json`，包含测试问题、已校验回复、token 用量、耗时与估算费用，不含密钥。日志仍可能含玩家输入，默认不提交；需要分享时仅提取必要的脱敏结果。

## 接入边界

新增 `ILLMClient`、独立认知快照、OpenAI HTTP 实现与本机限额。提示只含当前 NPC 的已知命题及来源；输出为 `reply / cited_beliefs / action`，使用严格 JSON Schema，并在本地再次校验。[结构化输出文档](https://developers.openai.com/api/docs/guides/structured-outputs)

本轮 `action` 只允许 `none`。引用不属于该角色、隐藏信息词表命中、格式损坏、拒绝或截断时，返回规则兜底台词，不展示未经校验的输出。词表只能覆盖当前有限命题，可能误判否定句，也不能检测所有改写；三次测试不能证明完整语义可靠性。

当前不改动 `WorldState` 或关系、物品和任务，不承诺完成完整游戏对话 UI。未来把回复接入正在运行的游戏时，必须在展示或执行前复核 `LlmRequestEnvelope` 的局代际、最新请求和状态版本，并补充 Executor 的权限、目标和幂等检查。

## 后续验证方式

### 首次实测记录

2026-11-04，本机命令行真实调用 3 次，均通过结构、引用和当前词表校验；无重试，无额外付费工具。合计输入 1,261 tokens、输出 179 tokens，缓存输入为 0，按当前单价估算 **USD 0.0002156**（约 USD 0.000216）。这不是平台账单读数，尚未核验实际余额和赠送额度扣减。

| 角色 | 实测表现 | 请求耗时 | 估算 USD |
| --- | --- | --- | --- |
| 阿禾 | 说明看到小川拿走工具，明确不知道现在的位置，区分猜测与目击 | 4,527 ms | 0.0000706 |
| 小川 | 回答工具在公共雨棚收纳箱，并说明归还经历 | 1,592 ms | 0.0000752 |
| 阿木 | 说明小川经自己同意借用，并否认偷窃 | 3,050 ms | 0.0000698 |

37 项离线测试通过，包含 HTTP 错误、取消、引用越权、隐藏位置、并发和预算反例。共享 C# 代码的 .NET 构建通过，编辑器菜单脚本也已引用本机 Unity 6000.3.23f1 的托管程序集单独编译通过。本轮没有可连接的小镇 Unity MCP 实例，资源导入、菜单点击和完整游戏运行仍待 Unity 内验收；模型用语的自然程度也需要真人试玩。三条结果仅证明这次小样本链路可用，不代表广泛稳定性。

### 继续迭代

先积累固定小样本，记录“是否理解、是否越界、是否可执行、等待多久、花费多少”。日程、移动、常规闲聊继续规则驱动。大型评估先用录制响应和模拟 client 回归，再批准一小批真实请求。CI 永远只运行离线测试。

扩大测试时明确：用哪个模型、多少用例、每条重复多少次、预计输入/输出、总预算和停止条件。不得把赠送额度视为无限调用授权。
