# OpenAI 接入与成本规范

更新：2026-11-09。适用于当前《龙眠镇》；v3 灰盒客户端、Smoke CLI 和旧付费菜单已退役。首次标准对话的授权与实测事实保留在 [历史记录](history/v3/OpenAI标准对话首次验证.md)，其中旧命令不再可执行。

## 1. 默认离线，显式授权才联网

- 打开工程、普通 Play、CI、单元测试及不带 `--live` 的研究 CLI 均默认离线，不读取真实密钥、不产生模型费用。
- Unity 菜单 `Town / Dragonsleep / AI 提供方` 可选择“下一局对话验证（最多 3 次）”或“下一局六机制真实模型（研究模式）”。授权在创建提供方时消费，退出 Play 清除；不自动授予下一次 Play。具体菜单名称以当前 Editor 为准。
- CLI 只有显式添加 `--live` 才使用真实提供方。真实请求按有限案例、种子和夜晚数结束，不启动后台持续调用。
- 对话授权只将 `Dialogue` 路由至在线提供方，其余任务离线；六机制研究使用独立的 `OpenAiRunProfile.SixMechanismResearch`。

```bash
# 离线：不需要密钥，HTTP 由测试替身提供
dotnet test dotnet/Town.sln --configuration Release

# 离线规划基线；只有显式添加 --live 才联网
dotnet run --project dotnet/Town.Research --configuration Release -- --plan --seeds=10
```

依赖已还原时可加 `--no-restore`，避免包还原联网。带 `--live` 的命令不是常规验证步骤；执行前必须确认适用的用户授权，而不是把文档中的示例当作新授权。

## 2. 模型与费用估算

当前默认模型固定为 **`gpt-6-luna`**，使用 Responses API、严格 JSON Schema、`reasoning.effort=none`、`service_tier=default`。不自动升级模型，不在失败时切换模型兜底，不启用搜索、文件、图像或语音等额外付费工具。

`OpenAiPolicy` 保留 2026-11-04 核对的文本价格：每百万 tokens，输入 USD 0.10、缓存输入 USD 0.01、输出 USD 0.50。这是代码采用的估算基准，不代表本轮重新核价或平台账单；价格变化应单独核实并更新。参考：[模型说明](https://developers.openai.com/api/docs/models/gpt-6-luna)、[价格表](https://developers.openai.com/api/docs/pricing)。

费用只根据返回的 `usage` 估算并标注“估算”。缺少 `usage` 时为未知（`null`），不得报告为零。账本的 `ReservedUsd` 是请求前预留估算，不是实际扣费。失败、超时或取消途中也计次并保留预留，不能凭失败推断没有费用。没有平台证据，不声称验证过余额、赠送额度或实际扣款。

## 3. 标准对话与六机制研究分开

用户于 2026-11-08 先要求足量真实实验，随后明确“预算无上限，能实现我的需求和目标就行”。该授权覆盖本轮六机制、连续世界演化、失败适配和复验，不因扩量或费用重复询问；不意味着启动无终止条件的自动调用，也不改变普通对话配置。

| 项目 | 标准对话 `Dialogue` | 已授权六机制研究 `SixMechanismResearch` |
| --- | --- | --- |
| 单轮 / UTC 当日请求 | 最多 3 / 20 次 | 不以费用或每日次数停止；按有限实验结束 |
| 单次输出 | 最多 384 tokens | 最多 768 tokens |
| 完整请求 JSON | UTF-8 最多 12 KiB | UTF-8 最多 12 KiB |
| 并发 / 超时 | 1 / 30 秒 | 1 / 30 秒 |
| 自动重试 / 模型兜底 | 均无 | 均无 |
| 请求前预留估算 | 每次 USD 0.002 | 继续在原账本逐次记账 |
| 单轮 / 当日预留上限 | USD 0.01 / 0.05 | 本轮研究不以该金额阻断 |
| 额外付费工具 | 不启用 | 不启用 |

参数位于 `unity/Assets/Town.OpenAI/OpenAiPolicy.cs` 和 `OpenAiRunProfile.cs`。研究能力包括对话、行动提案、居民自主计划、导演事件、造物和多步计划；授权不应被复制成未来 SDK 或其他工程的默认额度。

账本位于 `.local/openai/budget-YYYY-MM-DD.json`，发请求前加锁写入；不得删除、重置或换目录绕过记账。它只约束使用本入口的同一工作区，不是 OpenAI 组织级硬额度，也不覆盖其他工程、机器或直接请求。曾见的 USD 200 界面额度不是本项目的支出授权或实时余额。

## 4. 密钥与数据边界

- 密钥只保存在仓库根目录被忽略的 `.env.local`，变量名 `OPENAI_API_KEY`。不要打印或把全文读入工具输出、聊天、日志、截图、Unity 资源、构建产物和 Git；`.env.example` 只能有空变量。
- 当前读取器只取本仓库配置，不回退其他工程的进程环境密钥。endpoint 固定为 `https://api.openai.com/v1/responses`，禁用 HTTP 自动重定向，不通过环境变量转发给第三方代理。
- `store=false` 不等于平台零保留承诺。面向其他玩家发行前，密钥与费用控制必须迁至受控服务端。
- 对话只发送当前居民冻结的 `NpcPerceptionView`；其他机制发送按角色裁剪的 `TaskPerceptionView`。行动只看玩家可见场景，造物只看可用材料，居民计划只看本人认知，导演只看汇总与公共事件，多步计划只看玩家已知事实及系统生成的重规划上下文。
- 完整世界快照、其他居民私有认知和本地文件不得发给模型。完整快照只留本地回放；轨迹也可能包含玩家输入和私有信息，分享前脱敏，不把本地私有记录视作公开日志。

## 5. 输出不是已执行动作

`OpenAiDragonsleepProvider` 只接受经过验证的冻结视角请求，并从快照重建允许的载荷。响应还要经过本地结构、引用、权限与规则校验；错误、过期、取消、拒绝或截断不能绕过执行边界。

- 对话 `action=none`；台词不表示移动、交易、承诺或物品转移已经执行。
- 其他任务由 `DsExecutor` 在候选世界中裁决，核对状态哈希后提交并产生回执。
- 造物先展示图样，玩家确认后才消耗材料与时间；不是任意生成网格。
- 多步计划只提案，玩家确认后由执行器逐步提交；重规划必须依据当前合法感知，不能把未执行预测当成事实。UI 接线与验收另按 M4 任务记录。

本地校验不能证明任意语义都可靠。M3 的低信任求助与否定约束仍未通过，见 [闭环复验](归巢规划闭环复验_2026-11-09.md)。六机制实测与局限见 [研究报告](龙眠镇_AI六机制实测报告_2026-11-08.md)。CI 和常规整理只跑离线回归；真实调用、费用证据和真人玩法验收分别记录。
