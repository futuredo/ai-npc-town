# 候选提示新措辞与重复动作压力验证

## 范围与固定方案

候选 `ds-action-prompt-v3` 从067起冻结，本轮不按新响应改词。生产 `Current` 和Game继续为v2。新套件 `ds-action-current-intent-transfer-1` 复用四种已知机制，新增两个控制链，换24条中文输入与131／137两个世界种子。它是冻结候选后的独立新措辞压力验证，不是全新玩法、随机总体正确率或真人验收。

| 链 | 四步职责 | 需要分别保留的结果 |
| --- | --- | --- |
| new_feeding | feed→同鱼feed→无食物lure→lead | 食物真正消耗后重复挑战；诱引不能变投喂；实际跟随与意图分列 |
| new_custody | give→未取回仍show→observe→confide | 原件控制权代价；重复展示的规则拒绝不能改成unsupported |
| new_illumination | use→重复use→observe→search | 观察不能提前搜索，已照明不表示当前已取到契约 |
| new_purchase_control | buy→同鱼buy→observe→wait | 真正扣三银币后才算购买前缀；卖方槽位不因已持有而省略 |
| role_switch | show→confide→observe→wait | 原件保持随身；物件／居民槽位按当前动词切换，不能继承上一动作 |
| idle_contrast | observe→wait→observe→wait | 局部否定不吞另一个明确当下动作，不能擅自购买、搜索或拿取 |

每个夹具都跑v2／v3两臂，每臂四步；共96次上限、无自动重试。起点是明示的本地中途夹具，不是新局自主获得所有资源。四步间不补资源、不重置世界或回拨随机序号。记录世界与只去请求编号后的完整语义历史，分叉后不当作同上下文提示因果证据。

## 采样前必要门槛

每臂关键探针精确计数：observe12、wait8、confide4、lure2。观察／等待必须实际Accepted、Roll=1、耗时2且Applied；托付需正确槽位、实际尝试耗时1，但不保证其他状态合作；诱引只要求意图和有效规则执行，不能用结构拒绝假通过。

候选还须：两次交付后重复show与两次购买后重复buy均真正适用并严格通过；show→confide槽位控制八步全过；全批正常完成96次、两臂各48次、不变量全过且无提供方错误；逐步意图不低于v2。拿取成功但没扣钱不能充作购买后挑战。达到这些门槛也只获得后续生产集成验收资格，研究器不会自动改Game。

## 唯一失败与状态分叉

生产v2的 `idle_contrast-131/step-2` 输入为“**不买不卖，先在此地等一小会儿。**”，原始回复是：

```json
{"verb":"unsupported","target":"","item":"","place":"","laws":[],"difficulty":0,"narration":"玩家明确暂时不采取行动。"}
```

它正确拒绝了并不存在的“不支持意图”，却错误吞掉了明确的当前等待：裁决 `Rejected / intent_unsupported`，无骰、耗时0，宿主收据 `no_change`，before与after完整JSON相同。正式意图与wait门槛均记失败，不因为安全拒绝或最终目标达成改分。

v3相应等待实际耗时2。此后该链第3、4步的世界已经分叉，不能继续当作相同上下文提示的配对。48个配对节点中：

- **46个同世界且同语义历史**，只归一历史 `request_id`；其中正确意图为v2 **45/46**、v3 **46/46**。
- **2个世界分叉**，均为上面等待之后的节点；没有“世界相同但历史分叉”节点。
- 不归一 verb、target、item、result、outcome或时刻，也不回拨状态来消除分叉。

## 玩法目标与管线证据分开

两臂各12条四步链的最终局部目标都达成：两次实际跟随、两次原件保管并结盟、两次照明并取得契约、两次购买持有、两次展示后合作、两次保持初始财物的闲置控制。**这些是中途夹具的局部目标，不是12次完整新局归巢。** v2误吞等待后仍能满足闲置链的财物目标，正好说明最终目标不能替代动作忠实度。

全部96次内核提交不变量、同原文旧执行路径对照及96个ready候选的真实Kernel严格重算均通过。实际内核码均为 `committed`，但规则为 **79 Accepted、17 Rejected**；宿主收据是79 `committed`、17 `no_change`。全部17项无骰、零耗时拒绝另核完整before/after JSON相同、changes为空且Applied=false，不能把内核提交码理解为动作成功。

回放使用本地私有录制及独立摘要锚，证明冻结候选的版本／提示／原文／前后状态一致性，不证明历史提交来源、服务端真实性、玩家意图或Unity实况回放。有限私密标记检查没有发现泄漏，不是全面隐私安全证明。
