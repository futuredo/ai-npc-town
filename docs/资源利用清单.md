## 5. 当时的后续建议：怎样“多用”，而不是“多堆”

1. 把现有工作站的书、晶体、借用部件接成可查、可试、可归还的对象，产生执行/信息回执；比再搬十种桌子有价值。
2. 将已验证的交谈/拒绝/庆祝动作绑定角色条件和实际结果，补一条真实拿放交接链，保证手、物件、权限同时正确。
3. 复用现有 UI 包完成来源、条件、失败缺口和结尾，不让玩家面对一排无解释的工程按钮。
4. 需要新实验空间时再从现成室内/森林/要塞场景开副本，不凭空采购或把每套场景都塞进一个巨型地图。
5. 六类 AI 的研究增量仍要独立验证：人工候选和现成资产只证明执行/表现可接，不能证明开放语义、社会决策、GM 或自主多智能体已经实现。
