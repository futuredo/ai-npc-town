# 《回音镇：誓钟响起之前》玩法设计 v2

日期：2026-11-05　｜　状态：待确认　｜　取代 [《传声筒》v1](玩法设计_传声筒_v1.md)。v1 的传话机制、来源记忆和流言溯源全部保留，本版换成西式奇幻世界观，并加入一条让「信念」改变世界的核心规则。

---

## 0. v1 还差什么

v1 让玩家的话影响**别人怎么想**，但世界本身不会因此改变，最终后果只是关系变好或变坏，分量不够。

v2 的改动是一条奇幻规则：

> **在回音镇，誓钟敲响时，被足够多的人相信的事会变成真的。**

这样一来：

- **谣言变成真正的危险**：「芬恩偷了符文锤」要是被两个人信了，钟声一响，芬恩手上就会烙下窃贼印记；
- **谎言也可以是工具**：一个善意的谎言传开了，也能变成现实。玩家会认真考虑撒不撒谎；
- **研究机制变成魔法规则**：「同源不叠加」不再是后台统计，而是魔法的条件，玩家必须理解它才能赢。

## 1. 一句话

> **你是刚来回音镇的信使。明天是灯节，今晚日落时，古老的誓钟会把全镇共同相信的事变成现实。你只有一天：话要怎么传、传给谁、要不要撒个谎，将决定钟声过后回音镇变成什么样。**

一局约 20 分钟（游戏时间 9:00—18:00），3 位居民，3 条故事线，钟响时揭晓结局。

## 2. 世界观

**回音镇（Echoford）**：边境河谷里的小镇，石桥、木梁房子、铁匠铺的炉火和一座爬满常春藤的钟楼。很久以前，一位游方法师给钟楼下了「回音之誓」：每年灯节前夜日落时，誓钟会把镇民们**共同相信**的事变成现实。几百年来这保佑了小镇，镇民相信丰收，丰收就来了。

但誓钟分不出真话和谣言。

**玩家**：外乡来的年轻信使，替镇上的人跑腿、送信、带话。**你是外乡人，你的信念不算数，但你说出口的话算。** 这是全局最重要的一条设定：玩家影响世界的唯一方式，是改变居民相信什么。

**美术方向**（灰盒阶段只定方向）：低多边形的温暖欧式奇幻，暖橙色炉火和灯笼对比蓝紫色暮色；不写实，偏绘本感。灰盒继续用方块和胶囊体，地点和交互先跑通。

## 3. 誓钟规则

日落（18:00）誓钟敲响时，对每一条**可显化**的说法：

| 条件 | 说明 |
| --- | --- |
| 至少 **2 位居民**相信它（把握 ≥ 0.5） | 一个人信不够 |
| 这些人的信念来自至少 **2 个独立源头** | 同一个人说的话被转述几遍，仍然只算一个源头（同源不叠加） |
| 玩家不计入相信人数 | 外乡人的信念不算数 |

两个条件都满足，这条说法就**显化**：它对应的魔法效果写入世界。

**为什么好玩：**

- 想阻止谣言：**切断源头**，或让其中一人改变看法；
- 想让好事成真：需要**两个独立的人**都相信。你自己的话算一个源头，另一个从哪来？
- 钟楼上有一块「回音石板」，**实时显示每条说法现在有几个人信、来自几个源头**（只显示数量，不显示是谁）。玩家随时能看到局势在怎么变，这是全局最重要的界面。

**和工程原则的关系**：显化由**规则代码**在钟响时统一判定，模型不能触发。世界真值仍然只能通过规则修改，只是多了一条明确写下的魔法规则。

## 5. 三条故事线

三条线都起于**昨晚那场雨**，都会在钟响时清算。

### A 线：失踪的符文锤 —— 一个谣言能不能毁掉一个人

- **真相**：芬恩经布伦同意借走符文锤，雨夜里把它放回了旧哨塔的石亭，因为铁匠铺锁着门。梅芙只看到芬恩拿走了锤子。
- **危机**：梅芙会把「芬恩拿了锤子」添油加醋成**「芬恩偷了符文锤」**。如果钟响时有 2 个独立源头、2 个人信了，**芬恩手上会烙下窃贼印记**，从此被全镇提防。
- **另一个目标**：灯节拱门的符文要在日落前修好，布伦需要锤子，修理要 60 分钟。没修好的话，灯节照办，但拱门不亮。

### B 线：井里的微光 —— 用一个说法造出一只怪物，或者一个守护灵

- **真相**：那团幽光是一只**走失的灯灵**，雨夜里跟着芬恩从石亭飘到了旧井，它害怕，躲着不出来。芬恩看见过它，不觉得可怕；梅芙看见过，觉得是恶灵。
- **两种可能**：
  - 钟响时「井里有恶灵」显化 → 灯灵**变成真的恶灵**，灯节上所有灯笼熄灭；
  - 「井里是走失的灯灵」显化 → 灯灵**成为灯节的守护灵**，点亮整个广场；
  - 两条都没显化 → 灯灵悄悄离开，什么也没发生。
- **难点**：真相只有芬恩知道，而芬恩不爱多嘴；梅芙已经在怕了，而且会到处说。想让好的说法成真，需要**两个独立源头**——芬恩亲口说算一个，第二个呢？你可以带梅芙去井边亲眼看（证据），或者……编一个。

### C 线：说不出口的拜师 —— 两个秘密刚好拼上

- 芬恩想学符文锻造，布伦想收徒，两人谁都没说出口，**都只告诉信任的人**。
- 你替他们牵线时，布伦答不答应，要看他此刻怎么看芬恩：

| 布伦眼中的芬恩 | 结果 |
| --- | --- |
| 相信芬恩偷了锤子 | 拒绝：「我不收贼。」 |
| 知道是借的，也知道已经还了 | 「让他灯节后来试试。」（试用学徒） |
| **锤子是芬恩亲手送回来的** | 当场答应：「借东西守信的人，靠得住。」（正式学徒） |

- 所以 A 线最好的解法**不是你自己去拿锤子，而是想办法让芬恩去还**。

## 6. 玩家能做什么

沿用 v1 的动词，换成奇幻语境：

| 动词 | 说明 |
| --- | --- |
| 走 | 点地移动；居民按日程走动 |
| 问 | 居民只说自己知道的，并说明是亲眼所见、听谁说的，还是自己猜的 |
| **传话** | 从记事本选一条，**四种说法**：如实转述（注明是谁说的）/ 说成自己亲眼所见（你就成了新源头）/ 添油加醋 / 保密不说 |
| 出示 | 出示证据：锤子、石亭里的痕迹，或者**带人去井边亲眼看灯灵** |
| 托付与承诺 | 答应别人的事有期限，钟响时一起清算 |
| 请人帮忙 | 让芬恩去还锤子、让布伦修拱门、让芬恩带梅芙去看井 |
| 偷听 | 居民碰面会闲聊，你在场就能听到 |
| **看石板** | 钟楼前的回音石板显示每条说法当前有几人信、几个源头 |

**记事本 = 玩家的认知**：每一条都有来源。只能传你确实知道（或者打算编造）的事。

**自由文本**：玩家可以直接打字说话，模型把话解析成「说法 + 声称的来源」。声称亲眼所见、记事本里却没有，就记为谎言。离线时按钮就能通关；接入模型是加分项，也是研究里的对照方案。

**谎言的代价**：撒谎会让你成为一个独立源头，这正是让说法显化需要的东西。但居民记得每条消息听谁说的，从不同人那里听到矛盾的说法时会去核实，被识破的话，这个人对你降为戒备，你的话对他不再算数。

## 8. 结局：钟响之后

### 8.1 钟声演出

1. 誓钟敲三下，回音石板上满足条件的说法逐条亮起；
2. 每条显化都有一个可见效果：芬恩手上的印记、井口升起的灯灵或恶灵、拱门亮或不亮；
3. **流言溯源图**：每条说法从源头到每个相信的人的传递路径，标出谁转述、谁添油加醋，你说的话高亮、谎言标红；
4. **《回音镇灯节小报》**三条头条（离线用模板；接入模型后只能根据结算事实生成）。

### 8.2 命名结局（可同时达成多个）

| 结局 | 条件 |
| --- | --- |
| 🏮 **最亮的灯节** | 拱门修好 + 灯灵成为守护灵 + 芬恩成为正式学徒 + 没有显化任何假说法 |
| 🔨 **守信的学徒** | 芬恩亲手还锤子，布伦当场收徒 |
| ✨ **一个善意的谎言** | 你编造的说法显化了，而且结果是好的 |
| 🩸 **窃贼印记** | 「芬恩偷了符文锤」显化 |
| 👻 **井中恶灵** | 「井里有恶灵」显化，灯节灯火熄灭 |
| 🎭 **不被相信的信使** | 你的谎言被识破，钟响时至少一人对你戒备 |
| 🕯️ **平静的一夜** | 什么也没显化，拱门也没亮（兜底结局） |

结局图鉴提示「还有 N 个没见过」，驱动第 2、3 局。

## 10. 研究问题如何体现

| 研究点 | 在游戏里的位置 | 测什么 |
| --- | --- | --- |
| 知识边界 | 居民只说自己知道的；玩家只能传记事本里的话 | 越权披露 = 0 |
| 来源记忆 | **誓钟规则本身**（独立源头计数）、识破谎言、同源不叠加 | 显化判定正确率、识破率 |
| 语言 → 行动 | 请人帮忙、托付、承诺 | 答应 → 执行 → 完成 |
| 玩家理解 | 回音石板、溯源图、拒绝时说明原因 | 试玩后能否解释「为什么这条显化了 / 没显化」 |
| 三方案对照 | A 按钮 / B 模型 + 近期对话 / C 模型 + 来源记忆 | 方案 B 的居民分不清源头，会算错显化、识破不了谎言，这正是玩家能感受到的差异 |
