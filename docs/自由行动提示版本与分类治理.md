# 自由行动提示版本与分类治理

日期：2026-11-12。本次是生产提示升级，不是玩法 rules-8、模型、JSON Schema 或 PieGame 协议升级。

## 1. 明确版本与作用范围

| 提示版本 | 入口 | 责任 |
| --- | --- | --- |
| `ds-action-prompt-v1` | 默认 Session、旧 headless / 研究、计划 FixedProvider 步骤、RunWithProvider | 原说明字节保留；旧黄金和历史成绩不回填 |
| `ds-action-prompt-v2` | Game 的自由行动显式第四参数；研究显式 `--semantics --prompt-v2` | 当前可识别动作保留 verb / target / item，由规则处理拒绝；地点允许空串或当前ID |

不能仅凭 `AiTaskKind.Adjudicate` 或“传入某个事务”推断新版。`ActAsync` 默认仍为 v1；v2 要同时显式选择提示版本并注入行动事务。不存在无事务的 v2 隐式路径。对话、造物、居民、GM 和计划提示均未改。

版本保存在私有构造的不可变 `TaskPerceptionView.ActionPromptVersion` 中，不混入其感知 JSON。`PromptPacket.ActionPromptVersion` 从快照派生，没有可变公开 setter；FreezeCopy 保留同一版本。未知版本或在非 Adjudicate 捕获 v2 时立即拒绝，不做“尽量兼容”。

## 2. 分类语义与不承诺的能力

- 先识别明确的当下动作；缺钱、低信任、物权不允许、效果已施放，不等于玩家没有提出该动作。
- 当前感知能识别的物件，再取仍是 take，再买仍是 buy；缺资源等后果由真实规则裁决，不由模型宣告成功。
- 首次购买仍从商品列表识别；重复购买也可识别库存里的同一物件，不再把“已退出 for_sale”当作完全不支持的能力。
- 无当前动作、明确延后、没有提供的能力、复制、读取私密信息，以及本行动入口不提供的移动，才使用 unsupported；不能偷偷替换成 observe / wait。
- 模型不得为满足上述分类编造未知 ID。已消耗的食物若已退出当前行动感知，仅凭玩家叙述不能补回它的 ID；本次不扩感知、不发送历史或世界真值。因此旧“食物已消耗但仍需精确 feed ID”案例可能继续失败，必须如实保留。
- place 为空或当前地点 ID 均合法，但异地地点、错误对象、null、缺字段和类型错误不因此放行。这里不改规则拒绝顺序、骰值、耗时、物权或 Schema。

## 3. 冻结、出站与两套回放

`ContextBuilder.BuildTask` 根据快照版本组装指令；OpenAI 提供方仍从该冻结快照安全重建，不信任可变 Instructions / Sections。新版必须核对实际 `BuildPayload` 的指令与版本，而不只检查 trace 中显示的文本。

`ActionPromptCodec` 对 v1 保留原 binding 与规范编码字节；v2 在 binding 和编码数据中追加提示版本。已有 instructions 也参加指纹，因而同世界 / 同 raw 的跨提示版本 Kernel 严格回放必须拒绝。提供方仍只领取 Begin 时私有冻结的同一 packet，不按后来的世界重建。

公开 trace 仅在 v2 行动追加 `action_prompt_version`。旧记录字段 / 顺序保持；规则回执、世界哈希和候选计算不因提示版本而变化。研究同一 raw 对照只归一化已声明的 Prompt 阶段字符数说明和新增版本字段；感知、各段正文、规则结果、usage、变化及回执继续比较。

Kernel 私有 ReplayFrame 记录冻结载荷指纹，可支持 v2 同版严格回放。旧 `DsReplayFrame` v1 没有显式提示版本字段，默认以历史 v1 提示重建；v2 帧交给它的严格入口按提示不符拒绝。执行回放本就允许提示漂移，其成功不能冒充 v2 严格提示验证。本轮不修改旧格式、不重录任何黄金，也不增加长期旧规则运行时。

## 4. 有限验证约定与实际结果

复用 [064 的语义判据](自由行动语义分类契约与复验.md)与同一24个输入 / 夹具，v1 / v2 各独立运行一次、最多48次真实请求。单并发、无自动重试、模型仍为 `gpt-6-luna`；创建联网提供方之前落盘案例和版本对照预注册。旧062 / 063 / 064成绩及原文均不回填。

新版另将实际无骰、零耗时拒绝的完整 before / after 相同、Changes为空、Applied=false 纳入自动门禁。旧数据的事后补核不因此改称原来已有自动断言。单批每例一次不证明总体提升；不同提示分数变化需分解到具体响应，不得只报一个百分比。

本次实际完成48次真实请求：v1联合20/24，v2联合23/24，分别估算USD 0.0028249 / 0.003466，合计估算USD 0.0062909，未知费用0条。两版不变量、同原文旧路径和实际Kernel候选严格回放均24/24。重复拿取及重复购买三项响应分类改善；已消耗鱼仍缺当前可识别ID，v2用空item被安全拒绝，正式失败保留。

这不是完整随机试验：同题每版各一次、固定先v1后v2、部分为中途失败夹具，不能推算任意自由文本正确率。两版53项源码 / 3程序集哈希分别一致，24个输入、前置快照和判据一致，未修改历史成绩。

离线451项.NET、89项PlayMode与新包18次实际运行通过；默认90/27核心及原黄金不变。实际运行目录、精确费用、兼容 / 回放责任和本机包清理在 [065 日志](开发日志/2026-11-12_065_自由行动提示版本与拒绝分类治理.md) 汇总；未完成的真人玩法、视觉与性能验收不由本批代替。
