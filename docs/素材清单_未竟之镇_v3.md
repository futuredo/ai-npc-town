## 1. 风格定位：一本正在被上色的书

**一句话：** 铅笔线稿 + 水彩上色的立体绘本。没人相信的东西是铅笔稿，被写进正文的东西是墨线加水彩。

| 项目 | 定位 |
| --- | --- |
| 造型 | 简单低多边形，轮廓清楚即可；**细节靠着色器的线条和纸纹，不靠模型面数** |
| 渲染 | 一个统一的「草稿 / 墨线 / 上色」着色器，参数 `_Ink` 0—1 连续变化；外描边 + 排线阴影 + 纸纹 + 水彩晕染 |
| 色调 | 纸色（米白）为底；上色后是低饱和水彩：暖黄、砖红、灰蓝；黄昏时墨色从天边洇开 |
| 特殊色 | **红墨水**只用于谎言；**墨黑**用于落墨；这两种颜色在其他地方不要用 |
| 镜头 | 现有斜俯视透视相机不变 |

**为什么这条路线最省素材：** 风格由一个着色器统一，模型只要「形状对」。现有灰盒几何体套上着色器就已经是可展示的画面；正式模型来自不同包也不会风格打架。

**通用风格关键词：**

- 中文：手绘线稿、铅笔素描、水彩、绘本、纸张质感、墨水、钢笔画、速写风格渲染
- 英文：`sketch shader`、`pencil shader`、`hatching shader`、`toon outline`、`watercolor shader`、`paper texture`、`storybook`、`ink wash`、`hand-drawn 3D`

## 3. 着色器与纹理（P0，W1 自制原型）

| 优先级 | 素材 | 数量 | 关键词 | 要点 |
| --- | --- | --- | --- | --- |
| P0 | **草稿 / 墨线 / 上色着色器** | 1 | `sketch shader unity`、`pencil hatching shader`、`toon outline shader built-in`、`watercolor shader` | 内置渲染管线；`_Ink` 0 = 淡铅笔、0.5 = 墨线无色、1 = 水彩上色；优先**自己写**，参考开源实现 |
| P0 | 外描边 | 1 | `inverted hull outline`、`outline shader` | 背面外扩法即可；线条略抖动 |
| P0 | 纸张纹理 | 2 | `paper texture seamless`、`watercolor paper`、`sketchbook paper` | 一张地面 / 天空用，一张 UI 用；可平铺 |
| P0 | 铅笔排线纹理（明暗 3—4 级） | 1 套 | `hatching texture`、`tonal art map`、`pencil strokes texture` | 按光照选排线密度 |
| P0 | 水彩晕染 / 边缘噪声 | 2 | `watercolor wash texture`、`ink bleed`、`noise texture` | 上色时颜色不铺满，边缘有晕开感 |
| P1 | 镇外白纸边界 | 1 | `paper edge`、`torn paper` | 世界尽头地面过渡成纸纹 |
| P2 | 墨迹溶解遮罩 | 1 | `dissolve mask`、`ink splatter` | 落墨时从墨点扩散上色 |

## 13. 去哪里找

| 类型 | 常见来源 | 授权注意 |
| --- | --- | --- |
| 着色器参考 | GitHub 开源实现、Unity 官方示例 | 只参考思路或使用明确开源许可的代码；拷贝代码要登记许可证 |
| 纹理（纸、排线、水彩） | ambientCG、Poly Haven、自己扫描 / 绘制 | ambientCG / Poly Haven 多为 CC0；**自己画最稳** |
| 低多边形模型 | Kenney、Quaternius、Poly Pizza | 多为 CC0；Poly Pizza 逐个看 |
| 人形动画 | Mixamo | 以条款为准 |
| 图标 | game-icons.net | CC BY 3.0，**需要署名** |
| 音效 | Freesound、Kenney 音效包 | 每个文件授权不同 |
| 音乐 | itch.io、OpenGameArt | 逐首确认 |
| 中文字体 | 霞鹜文楷、思源 / Noto 系列 | SIL OFL；以下载时页面为准 |

AI 生成的概念图可以用来定风格；如果用 AI 生成纹理或图标，要在清单里注明生成工具和使用条款。
