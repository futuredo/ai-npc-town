# 龙眠镇本机试玩与验证

本页针对 Unity 6000.3.23f1 / macOS 的离线试玩，不代表对外发行版本。主场景依赖本机已导入的商业环境、人物、龙和 UI；这些素材及 `.app` 不上传到仓库，不在许可尚未核实前再分发。

## 构建

先退出占用本工程的 Unity Editor；不要同时运行 PlayMode 测试或另一个构建。以下入口只读取既有主场景，不自动重建场景、不安装 Unity 模块，也不主动写 PlayerSettings / Build Settings。Unity / URP 本身可能生成缓存和序列化设置，构建后须检查 Git 状态，只恢复确认属于本次构建的生成差异，不覆盖别人的改动：

```bash
ROOT="/Users/sanwuwei/ai native项目-小镇"
UNITY="/Applications/Unity/Hub/Editor/6000.3.23f1/Unity.app/Contents/MacOS/Unity"
mkdir -p "$ROOT/.local/builds"

"$UNITY" -batchmode -projectPath "$ROOT/unity" -buildTarget StandaloneOSX \
  -executeMethod Town.Editor.DragonsleepPlayerBuild.BuildMacOs -quit \
  -logFile "$ROOT/.local/builds/Dragonsleep-build.log"
```

`.local/builds/` 保存带时间和随机后缀的新 `.app` 与同名 `.build.json`，不会覆盖旧包。以摘要中的 `result`、`buildResult`、错误数以及进程退出码共同判断结果；没有成功摘要不能称为构建成功。主场景缺失时先按 [README](../README.md) 准备本机素材与场景，不用空场景冒充成功。

2026-11-09 本机已实际构建并启动验证：`Dragonsleep-macOS-local-20261109-132840-229b05fb.app`，约 3.12 GB，构建 0 错误 / 57 警告，显式 Player 冒烟通过。该包不是对外发行版本；具体证据见 045 日志。

## 启动与操作

打开成功构建的 `.app`；点击开场“启程”后进入游戏。默认使用离线 `RuleProvider`，启动不请求 OpenAI，不需要密钥，不会自动规划或执行。

- WASD 移动，Shift 疾行；右键拖动、Q/E 和滚轮控制镜头。
- Enter 聚焦输入；“言 / 行 / 造”分别对应交谈、行动和造物。
- P 打开归巢计划：提出目标、选择取舍、确认后**逐步执行**；重规划仍需重新确认。它不是自动通关按钮。
- M 打开地图与结束时段，J 查看手记，Tab 查看规则回执。计划请求在途时可请求取消，但须等原请求真正结束才能继续；执行步骤已有的后果不会回滚。
- 结局卡可“查看现场”，底栏“结局”可重新打开卡片再来一局。终局不再允许地图传送；现场镜头不改变玩家、雏龙或结局的规则状态。
- 雏龙、母龙复用现有模型；卫兵岗位、铁笼、斗篷包裹是明确登记的灰盒占位，不是正式资产验收。

Player 的轨迹写入 `Application.persistentDataPath/dragonsleep/traces/`，不尝试写入 `.app` 或把构建包附近当作仓库。该目录与历史 `unfinished-town/` 存档无关，不删除历史玩家数据。

## 显式启动冒烟

下面仅证明实际构建能够加载主场景、离线会话、角色和必要 UI，**不证明完整玩法、真人手感、性能或视觉质量**。正常启动不传这些参数，就不会运行冒烟或自动退出。

```bash
APP="成功构建摘要中 outputPath 的绝对路径"
BIN="$(/usr/libexec/PlistBuddy -c 'Print :CFBundleExecutable' "$APP/Contents/Info.plist")"

"$APP/Contents/MacOS/$BIN" \
  --dragonsleep-smoke --dragonsleep-smoke-output "$ROOT/.local/builds/player-smoke-new.json" \
  -screen-fullscreen 0 -screen-width 1600 -screen-height 900 \
  -logFile "$ROOT/.local/builds/Dragonsleep-player-smoke.log"
```

输出必须是尚不存在的绝对本地 JSON 路径，父目录先存在；不要加 `-nographics`，否则无法证明 UI 布局。退出码 0 且摘要 `passed: true` 才是通过；1 表示验证失败，2 表示参数或摘要写入失败。
