# 《传声筒：集市前的一天》玩法设计 v1

日期：2026-11-05　｜　状态：待确认　｜　取代策划大纲 v0.2 中「单一找锤子事件」的玩法部分；角色、场景、三层数据分离和研究问题保留。

---

## 0. 为什么要改

v0.2 的「集市前的工具失踪」能验证系统，但作为游戏偏弱：

- 真相一问小川就知道，几分钟就能解开，**核心操作是跑腿**；
- 玩家的话只影响「谁知道什么」，**没有选择的代价和诱惑**；
- 结局主要是长凳修没修好，**没有让人想再玩一次的东西**。

我们手里最有特色的能力是：**每个居民只知道自己经历过或听说的事，而且记得是听谁说的。** 好玩的设计应该让这一点成为玩家每分钟都在用的东西，而不是藏在后台。

---

## 1. 一句话

> **你是小镇新来的跑腿。今天是集市前一天，人人都托你带句话——你可以原话转达、添油加醋、替人保密，或者干脆说个谎。话会在镇上自己传开，傍晚集市开张时，你会看到每一句话最后变成了什么样。**

一局约 20 分钟（游戏时间 9:00—18:00），3 位居民，3 条交织的小故事，6 种命名结局。

---

## 2. 好玩在哪里（四个支柱）

| 支柱 | 玩家的感受 | 靠什么实现 |
| --- | --- | --- |
| **话就是工具** | 「我说什么、怎么说，真的会改变事情」 | 传话面板 + 自由文本；居民按来源和性格决定信不信 |
| **流言有生命** | 「我没说过这话啊，怎么传成这样了？」 | 居民之间按日程碰面闲聊，阿禾会添油加醋；玩家能偷听 |
| **两个秘密刚好拼上** | 「原来他们都想要同一件事！」 | 三条故事线互相咬合：一条线的处理方式决定另一条线的成败 |
| **结局揭晓** | 「原来那句谣言是从这里开始的」 | 集市开张时展示「流言溯源图」和一份小镇小报，命名结局可收集 |

设计原则：**每一个结局都能看出原因**——溯源图把每条消息从源头到终点的传递路径画出来，包括你说过的每一句话。

## 3. 三条故事线

都发生在昨天下午那场雨里，都和公共雨棚有关。三条线**刻意交织**：一条线怎么解决，会影响另一条线的成败。

### A 线：失踪的锤子（原事件，改为入口）

- 真相：小川经阿木同意借走锤子，下雨时把它还到了雨棚收纳箱。阿禾只看到小川拿走。
- 冲突：阿禾随口说「小川拿了锤子没还」，一传就变成「小川偷了锤子」。
- 目标：集市前修好广场长凳（需要锤子，维修 60 分钟）。

### B 线：淋湿的布（新增，保密与托付）

- 真相：阿禾昨天在雨棚和人聊天，忘了收要在集市上卖的布，布全淋湿了。**她不想让别人知道**，怕被说不靠谱。
- 小川还锤子时看见了湿布（他知道，但不爱多嘴）。
- 解决办法：阿木能用锤子做一个晾布架（30 分钟）。但阿禾只告诉了你，并请你保密。
- 玩家的两难：直接告诉阿木 = 违背阿禾的托付；先回去问阿禾「能告诉阿木吗？」，她信任你时才会答应。
- **和 A 线咬合**：锤子只有一把，阿木要修长凳也要做晾布架，两件事加起来需要 90 分钟，锤子拿回来越早越好。

### C 线：说不出口的拜师（新增，牵线）

- 真相：小川一直想跟阿木学木工，但不敢开口；**阿木其实也正想收个徒弟**，只是没和任何人说过。两个人都只在信任你之后才会透露。
- 玩家的高光时刻：发现两个秘密正好对得上，替他们牵线。
- **和 A 线咬合**：阿木答不答应，取决于他此刻怎么看小川——
  - 阿木听信了「小川偷锤子」→ 拒绝；
  - 阿木知道「借了按时还」→ 愿意考虑；
  - **锤子是小川自己送回来的** → 阿木当场答应：「借东西守信的人，靠得住。」
- 所以 A 线**最好的解法不是你自己去拿锤子，而是想办法让小川去还**。玩家第一局通常想不到，这正是重玩的动力。

## 4. 玩家能做什么

### 4.1 动词

| 动词 | 说明 |
| --- | --- |
| **走** | 点地移动。居民按日程走动，要找人得知道他几点在哪。 |
| **问** | 问近况、问某件事。居民只说自己知道的，会说明「我亲眼看到 / 听谁说的 / 我猜的」。 |
| **传话** | 把记事本里的一条消息告诉某人。**四种说法**：<br>① 如实转述（「阿禾说……」）<br>② 说成自己看到的（「我亲眼看到……」）<br>③ 添油加醋（换成一条更重的说法，例如把 A1 说成 A5）<br>④ 不说（保密）|
| **出示** | 出示线索（锤子、湿布）。证据比转述更有分量。 |
| **托付 / 答应** | 接受居民的托付（保密、带话、帮忙），或者自己许下承诺（「集市前把锤子找回来」）。承诺有期限，兑现或违约都会被记住。 |
| **请人帮忙** | 让居民去做一件事（让小川去还锤子、让阿木做晾布架）。居民忙、累或不信任你时会拒绝，并说明原因。 |
| **偷听** | 两个居民碰面时会闲聊。你在同一个地点就能听到，偷听来的内容记作「偷听到 X 对 Y 说」。 |

### 4.2 记事本（玩家的认知）

记事本就是**玩家自己的认知库**，和居民用同一套结构：每一条都有来源（亲眼看到 / 谁说的 / 偷听到）和时间。传话时只能从记事本里选，所以玩家也受「知识边界」约束：**你不能转达你根本不知道的事**。

### 4.3 自由文本（模型加分项）

玩家也可以直接打字说话。模型把这句话**解析成命题、立场和声称的来源**（例如「我亲眼看到小川把锤子放回去了」→ A3 真，来源：声称亲眼看到）。程序拿它和玩家记事本比对：

- 声称亲眼看到、记事本里却没有 → **记为谎言**（玩家不会被提示，但居民之后可能识破）；
- 解析不出、含糊不清 → 居民反问澄清。

**离线规则模式下，四种说法的按钮就能把整局玩完**；自由文本是更自然的说法，不是通关前提。这也正好是研究里方案 A 和方案 B/C 的对照。

## 5. 流言系统：让话自己走

### 5.1 居民之间的闲聊

- 两个居民在同一地点停留时，按日程触发一次闲聊，各自转述自己**把握 ≥ 0.5** 的消息。
- 每个居民的转述风格不同：

| 居民 | 转述风格 | 结果 |
| --- | --- | --- |
| 阿禾 | **添油加醋**：把握不足时会往重里说 | 「拿走」→「偷」；「布湿了」→「布是次品」 |
| 阿木 | **只说有证据的**；听到指控会反问「你亲眼看见了？」 | 谣言到他这里通常会停下 |
| 小川 | **不爱多嘴**：只在被问到时说；涉及自己的坏话会很受伤 | 被冤枉后对传话者降为戒备 |

- 闲聊时会在头顶冒出对话图标；玩家在场就能偷听。

### 5.2 谎言会被识破

居民记得每条消息的来源。当一个居民从**不同源头**听到互相矛盾的说法，并且其中一条追溯到你时：

- 他会去找原始来源核实（日程碰面时发生）；
- 如果你说的是假的或者夸大了，**他会当面问你**：「你说你亲眼看到的，可小川说他那会儿根本不在雨棚？」
- 被识破：此人对你降为戒备，并可能告诉别人「这个新来的说话不靠谱」。

这一点直接体现了研究的核心：**只有保留来源的记忆（方案 C）才能识破谎言**；只看最近对话的方案 B 做不到。两种方案的差别，玩家能直接感受到。

### 5.3 同源不叠加

同一件事经两个人转述，如果源头相同，只算一份证据。「阿禾说的」和「听阿木说阿禾说的」不会让人更相信。这条规则防止流言靠重复刷可信度，也是研究的验收点。

## 6. 一局怎么走（参考路线，约 20 分钟）

| 游戏时间 | 现实时长 | 发生什么 |
| --- | --- | --- |
| 9:00 | 0—2 分钟 | 开场：你是新来的跑腿。阿木在广场对着坏长凳发愁：「锤子不见了。」第一份托付：帮他找锤子。 |
| 9:00—11:00 | 2—6 分钟 | 自由探索。阿禾在杂货铺八卦：「我看见小川拿走了锤子……」小川在送货路上。雨棚里有锤子和一角湿布。 |
| 11:00—12:00 | 6—8 分钟 | 关键选择出现：自己拿锤子回去，还是找小川让他去还？要不要把阿禾的话告诉阿木？ |
| 12:00—13:00 | 8—9 分钟 | 小川午休，请不动；阿禾和你熟了，透露湿布的秘密，托你保密。 |
| **14:00** | 10 分钟 | **阿禾到广场送货，和在场的人闲聊**——你上午说过的话会在这里发酵。玩家在场就能偷听。 |
| 14:00—17:00 | 10—17 分钟 | 收拾局面：澄清、道歉、牵线拜师、争取晾布架的时间。 |
| **18:00** | 18—20 分钟 | **集市开张**：结局揭晓。 |

时间设计：上午信息多、下午后果多。14:00 的闲聊是全局的转折点，玩家第一局多半会在这里第一次看到「我没说过这话啊」。

## 7. 结局：集市开张

### 7.1 结算三件事

1. **集市现场**：长凳修好了吗？阿禾的布摆出来了吗？小川和阿木站在一起吗？（灰盒阶段用文字和简单状态表示）
2. **流言溯源图**：每条在镇上流传过的消息画成一棵传播树，从源头到每个听说的人，标出谁转述、谁添油加醋，**你说过的话高亮显示**，谎言和失真标红。这是这个游戏的高光时刻，也是最直观的研究可视化。
3. **小镇小报**：三条头条概括今天发生的事。离线时用模板拼；接入模型后由模型根据**结算事实**生成，只能写已经发生的事。

### 7.2 命名结局（可收集）

| 结局 | 条件（示意） |
| --- | --- |
| 🌟 **最好的集市** | 长凳修好 + 布晾干摆出 + 小川拜师成功 + 没有人还信谣言 |
| 🔨 **守信的徒弟** | 小川亲自还锤子，阿木当场收徒（其他线不论） |
| 🤐 **守口如瓶** | 阿禾的秘密没有从你这里传出去，布也晾干了 |
| 🗣️ **流言之日** | 「小川偷锤子」传到了 2 人以上，并且到集市时仍没人澄清 |
| 🎭 **被识破的跑腿** | 你的谎言被至少一位居民识破 |
| ☂️ **临时座位** | 长凳没修好，大家坐着箱子逛集市（兜底结局，仍然有温度） |

一局可以同时达成多个结局。结局图鉴提示「还有 N 个没见过」，驱动第 2、3 局。

### 7.3 次日回访（可做）

每人一句，体现他们记住了你今天做的事。

## 8. 研究问题怎么体现在玩法里

| 研究点 | 玩法里的位置 | 怎么测 |
| --- | --- | --- |
| 知识边界 | 居民只说自己知道的；玩家只能传记事本里的话 | 越权披露 = 0 |
| 来源记忆 | 偷听、转述、同源不叠加、识破谎言 | 识破率、同源误判率 |
| 语言 → 行动 | 请人帮忙、托付、承诺 | 答应 → 执行 → 完成的落地率 |
| 玩家理解 | 流言溯源图、居民拒绝时说明原因 | 试玩后能否说出「谣言从哪开始、为什么阿木不收徒」 |
| 三方案对照 | A：按钮；B：模型 + 近期对话；C：模型 + 来源记忆 | 同一组剧本输入下比较识破率、失真率和玩家评价 |

研究问题保持不变：**「角色拥有带来源的记忆后，玩家能否更清楚地理解并影响 NPC 的行为？」** 新玩法让它从后台指标变成了玩家能直接感受到的东西。

## 11. 风险

| 风险 | 预案 |
| --- | --- |
| 玩家不知道该把话传给谁 | 居民会主动托付（「帮我问问小川……」）；记事本里标出「有人想知道这件事」 |
| 流言传播太随机、看不懂 | 闲聊只在日程固定的时间地点发生，并有图标提示；溯源图事后解释 |
| 撒谎没有代价或代价太狠 | 识破只降一档，可以道歉加出示证据修复；溯源图让玩家看清代价从哪来 |
| 三条线内容量超出工期 | B 线整条放在「应做」；必做部分只有 A + C 两条线 |
| 模型解析自由文本出错 | 按钮可以完整通关；解析结果先显示「你的意思是：……」让玩家确认，再计入 |
