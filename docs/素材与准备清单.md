## 素材交付规格（首版建议）

这些是项目的初始制作约束，不是现有素材已经达标的结论。

- 3D、米制、Y 轴向上；以少年与人形代理为比例样板，女巫、鹿骨与鸮另验碰撞/交互高度，不假定全员同骨架。模型脚底或约定支点为原点，Unity 内朝 +Z；缩放为 1，碰撞代理与渲染网格分离。
- 沿用当前斜俯视透视相机；以桌面 1920×1080 为首轮预览目标，同时检查 1280×720。正式平台和最低设备尚未锁定。
- 灰盒保持低细节、清晰轮廓，优先龙鳞尺度、鹿角/蛾斗篷/半影辨识与法术可读性；不先扩复杂室内。关键状态不只依赖颜色。
- 角色建议单体 5k–15k 三角面、1k 贴图起步，非人角色的骨架与屏幕占比另验；场景模块先用 1k 贴图，特写关键物体再评估 2k。以上只是导入预算，需实机测量后调整。
- 动画先用原地动画，移动由 NavMeshAgent 控制；Idle / Walk 循环，施法/交接用非循环或可重复片段，避免混用 Root Motion。
- 模型交付 FBX + 独立纹理 + 可编辑源文件；UI 图标 PNG（必要时透明背景），保留 SVG 等源文件；音效 WAV，音乐 / 环境音后续由导入配置压缩。
- 每件正式资源必须登记来源 URL、作者、许可证、署名要求、修改记录。未记录授权的资源不得进入发布包；生成概念图不等于可直接使用的 3D 模型。

## 收纳位置

| 路径 | 用途 |
| --- | --- |
| `art/source/` | 原始素材目录说明；大源文件放外部存储，登记相对引用，暂不引入 Git LFS |
| `art/asset-manifest.json` | 素材 ID、状态、来源、授权和 Unity 目标位置 |
| `art/asset-candidates-v4.csv` | 可筛选候选表：故事用途、价格、格式、转换工作与来源 |
| `unity/Assets/Town.Content/` | 后续正式导入的角色、环境、道具、UI、音频、配置与 Prefab |
| `unity/Assets/Graybox/` | 当前程序生成的临时材质，与正式素材分开 |
| `docs/开发日志/` | 大修改的目的、文件范围、验证结果、限制与下一步 |

## 到货 / 导入检查

先导入一个角色、一件道具和一块 UI 做样板：看角色比例与脚底、动画滑步、交互距离、中文显示、碰撞与导航、透明边缘和运行性能。样板确认后批量替换占位物，并更新素材清单；不直接覆盖整个灰盒场景。
