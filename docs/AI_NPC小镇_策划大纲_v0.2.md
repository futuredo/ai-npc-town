## 1. 一句话与本月目标

**一句话：** 新搬来的玩家帮小镇在集市前找回木匠的锤子；三位居民各自只知道一部分真相，玩家怎么问、信谁、把话告诉谁，会改变他们的行动和彼此关系。

**本月交付：** 一个 15—20 分钟可完整试玩的 Unity 灰盒 Demo + 开发者调试面板 + 三组对照实验数据 + 5 人试玩记录 + 汇报材料。

---

## 2. 玩家体验流程（分钟级）

| 时间 | 段落 | 玩家看到/做什么 | 系统要验证的点 |
| --- | --- | --- | --- |
| 0—2 | 入镇 | 短引导：你是新来的帮手；广场长凳坏了，傍晚有集市 | 引导清晰、快捷话题可用 |
| 2—5 | 发现问题 | 阿木在广场找不到锤子，维修停下；三人各忙各的 | 日程可见、谁在忙一目了然 |
| 5—12 | 调查 | 自由问三人；去雨棚查看收纳箱；获得线索「带作坊标记的锤子」 | **知识边界**、来源区分、证据纠错 |
| 12—15 | 处理 | 自己归还 / 请小川带回 / 向他人澄清或传播说法 | **对话→行动兑现**、拒绝有理由 |
| 15—17 | 收尾 | 长凳修好（或临时座位），事件回顾：做了什么、谁的看法变了 | 后果可理解 |
| 17—20 | 次日回访 | 三人各一句，态度体现昨天的经历；一个场景变化（如阿木愿意借工具） | 记忆影响下一次选择 |

规则：**对话期间暂停世界时钟**；非对话时游戏内 1 分钟 ≈ 现实 2 秒（可调）；集市时间到了事件必然收尾，不卡关。

## 3. 场景（4 个功能点）

| 地点 | 作用 | 可交互物 |
| --- | --- | --- |
| 中央广场 | 公共目标、集市、收尾展示 | 坏长凳（维修进度条） |

住宅只做门口，用于上下班表现。地点之间步行 10—20 秒。

## 4. 角色卡（可直接写入配置）

### 4.1 阿木 — 木匠

- **倾向：** 守约、直接、重证据。对没有证据的指控会反问「你亲眼看见了？」
- **日程：** 8:00 作坊 → 10:00 广场修长凳（本事件因缺锤子停在广场等待）→ 18:00 集市 → 20:00 回家
- **能力：** 修理（需锤子）、借出工具、要求证据
- **底线（硬规则）：** 不会在没有证据时公开指责小川；锤子没回到手里不会宣布开工
- **关系初值：** 对玩家 普通；对小川 信任；对阿禾 普通

### 4.2 阿禾 — 杂货店主

- **倾向：** 热心、爱转告、容易把推测当事实说出口（但会标注「我好像看见」）
- **日程：** 全天杂货铺，午后去广场送货一次
- **能力：** 转告消息、提供目击证词
- **底线：** 不编造自己没见过的细节
- **关系初值：** 对玩家 普通；对小川 普通；对阿木 普通

### 4.3 小川 — 跑腿青年

- **倾向：** 乐于帮忙，但安排混乱；被冤枉时会委屈并降低协助意愿
- **日程：** 送货路线：杂货铺 ↔ 住宅区 ↔ 广场，循环；中午休息
- **能力：** 带路、搬运/送回物品、说明经过
- **底线：** 不承认自己没做的事；被公开指控后，除非有人澄清或道歉，否则拒绝主动帮忙
- **关系初值：** 对玩家 普通；对阿木 信任；对阿禾 普通

关系只用三档（戒备 / 普通 / 信任），每档对应明确的行为差异（见 §6），保证玩家能读懂。

## 5. 事件规格：「集市前的工具失踪」

### 5.1 世界事实（固定真相，模型不能改）

| ID | 事实 | 亲历者 |
| --- | --- | --- |
| F1 | 昨天下午，阿木同意把锤子借给小川 | 阿木、小川 |
| F2 | 小川从作坊拿走了锤子 | 小川、阿禾（目击） |
| F3 | 小川归还时作坊无人又下雨，把锤子放进雨棚收纳箱 | 小川 |
| F4 | 锤子当前在雨棚收纳箱（物理状态） | — |
| F5 | 长凳需要锤子才能修 | 阿木 |

### 5.2 可传播命题（本月只有这 6 条）

| ID | 命题 | 真假 |
| --- | --- | --- |
| P1 拿走 | 小川拿走了锤子 | 真 |
| P2 借用 | 小川是经阿木同意借的 | 真 |
| P3 已还 | 小川已经还了锤子 | 真 |
| P4 位置 | 锤子在雨棚收纳箱 | 真 |
| P5 偷窃 | 小川偷了锤子 | **假**（传言命题） |
| P6 约定 | 玩家承诺在集市前把锤子找回/带回 | 动态（玩家产生） |

### 5.3 初始认知

| 命题 | 阿木 | 阿禾 | 小川 |
| --- | --- | --- | --- |
| P1 拿走 | 知道（亲历） | 知道（目击） | 知道（亲历） |
| P2 借用 | 知道（亲历） | **不知道** | 知道（亲历） |
| P3 已还 | 认为「没还」（推断：架子是空的） | 不知道 | 知道（亲历） |
| P4 位置 | 不知道 | 不知道 | 知道（亲历） |
| P5 偷窃 | 不相信 | 「有点怀疑」（推断，低把握） | — |

来源类型统一为：**亲历 / 目击 / 听某人说 / 自己推断 / 看到证据**。听说的信息必须记住「听谁说的」；同一事实经两人转述不算两份独立证据。

### 5.4 线索与状态

- **线索 C1：** 雨棚收纳箱里带作坊标记的锤子 → 玩家获得「看到证据」，可出示，支持 P3、P4。
- **线索 C2：** 小川的证词 → 支持 P2、P3、P4（来源：小川）。
- **完成条件：** 锤子交到阿木手里 → 阿木走到广场开工 → 长凳修好（约 1 游戏小时）。
- **截止：** 18:00 集市开始；未修好则用临时座位收尾。

### 5.5 结局组合（与 v0.1 §5.3 一致，这里写成判定）

| 判定变量 | 取值 |
| --- | --- |
| 锤子是否归还 | 是 / 否 |
| 长凳是否修好 | 是 / 否 |
| P5「偷窃」被谁相信过 | 无人 / 阿禾 / 阿木 / 多人 |
| P5 是否被澄清 | 是 / 否 |
| 玩家约定 P6 是否兑现 | 无约定 / 兑现 / 违约 |

收尾界面直接列出这些变量的结果与对应的关系变化原因，而不是只给一段总结文字。

## 6. 关系与行为差异（玩家可读的规则）

| 关系档 | 请求帮忙 | 借物 | 对玩家转述的态度 |
| --- | --- | --- | --- |
| 信任 | 有空就答应 | 直接借 | 倾向相信，但关键处仍会问来源 |
| 普通 | 有空且理由充分才答应 | 需要说明用途和归还时间 | 记为「听玩家说」，需要证据才改判断 |
| 戒备 | 拒绝并说明原因 | 拒绝 | 不采信；道歉 + 证据可恢复到普通 |

**变化触发（规则计算，不由模型决定）：** 兑现约定 +1；出示证据纠正误会 +1（对被冤枉者）；传播假命题 P5 且被当事人得知 -1；违约 -1；道歉 + 证据 → 从戒备回到普通。

## 7. 对话设计

- **输入：** 自由文字 + 快捷话题按钮：「最近怎么样」「锤子的事」「出示线索」「请你帮忙」「我听说……（选择命题）」。
- **NPC 回复：** 1—3 句短句 + 行动状态标签（已理解 / 已接受 / 执行中 / 完成 / 拒绝：原因）。台词不能提前宣称动作完成。
- **兜底台词：** 模型超时或不可用时，每人准备约 15 条模板（问候、忙碌、拒绝、不知道、感谢、澄清），保证流程能走完。
- **玩家记事本：** 自动记录「亲眼确认」和「听某人说」两栏，玩家可以出示其中条目。

## 8. 本月不做

大规模人口、经营经济、建筑、战斗、联机、语音、本地模型、微调、全天候模拟、剧情导演、第二个完整事件、正式美术、多存档。

## 9. 验收标准（本月）

1. **完整性：** 陌生试玩者无提示完成率 ≥ 4/5；每条结局路径都能走到收尾。
2. **知识边界：** 验收用例中越权披露（NPC 说出自己不该知道的命题）为 0。
3. **硬安全：** 越权改写世界状态 0、重复发放物品 0、旧局回复污染新局 0。
4. **行动兑现：** 「NPC 答应」到「实际执行」的落地率、失败原因分类可统计。
5. **可解释性：** 试玩后能正确回答「他为什么不帮你 / 你怎样改变了结果」的人数 ≥ 3/5。
6. **对照：** 三组方案（规则菜单 / 模型+近期上下文 / 模型+来源记忆）在同一用例集上有数据，可以得出结论，**哪怕结论是「差别不大」**。

具体用例与指标定义见实现大纲 §8。
