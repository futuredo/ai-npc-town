## 1. 风格定位

**一句话：** 温暖的低多边形欧式奇幻小镇，像一本会动的绘本。

| 项目 | 定位 |
| --- | --- |
| 造型 | 低多边形（Low Poly）或风格化（Stylized），比例略 Q，不写实 |
| 色调 | 白天暖黄、木色、石灰色；日落转橙紫；灯笼和炉火是画面主光点 |
| 材质 | 纯色块或简单渐变贴图为主，少用法线细节；**整套素材风格统一比数量更重要** |
| 镜头 | 现有斜俯视透视相机不变，素材要在中远景下轮廓清楚 |

**通用风格关键词（找素材时组合使用）：**

- 中文：低多边形 奇幻 小镇、中世纪 村庄、风格化 卡通、绘本风、温馨、灯笼、黄昏
- 英文：`low poly fantasy village`、`stylized medieval town`、`cozy fantasy`、`cartoon medieval`、`fantasy town kit`、`storybook`、`hand-painted low poly`

**最省事的路线：** 场景和道具挑**一套**风格完整的奇幻村庄包，通常能覆盖 70% 以上的需求；角色另找**一套**共用骨架的风格化角色包；动画用通用人形动画库。三套之间先比色调和比例，再决定。

| --- | --- | --- | --- |

| 角色动画 | **8 类** | +3 | 共用一套人形骨架 |
| 建筑 / 地标 | **7** | +3 | 钟楼、铁匠铺、旅店、石亭、旧井、灯节拱门、民居 ×1 |
| 道具 | **约 20 件** | +10 | 含 3 件剧情关键道具 |
| 自然 / 地面 | **约 10 件** | — | 树、石、草、路面、篱笆 |
| 特效 | **7** | +3 | 魔法显化是视觉高潮 |
| UI | **1 套框体 + 约 20 个图标** | — | 对话、记事本、回音石板、结局卡 |
| 字体 | **2** | — | 标题奇幻感 + 正文易读，都必须覆盖中文 |
| 音效 | **约 15 个** | +5 | 钟声最重要 |
| 音乐 | **3 首** | +1 | 白天、黄昏紧张、钟响结局 |

**合计（必需）：** 约 4 个角色 + 8 类动画 + 37 个模型 + 7 个特效 + 1 套 UI + 2 套字体 + 约 18 段音频。

## 12. 去哪里找

以下是常见来源，**授权以下载当时页面上的说明为准**，逐件登记：

| 类型 | 常见来源 | 授权注意 |
| --- | --- | --- |
| 低多边形模型（免费） | Kenney、Quaternius、Poly Pizza | 多数为 CC0；Poly Pizza 上各模型授权不同，要逐个看 |
| 综合付费 / 免费 | Unity Asset Store、itch.io、Fab | 按各自许可，注意能否用于汇报视频和公开演示 |
| 人形动画 | Mixamo | 需要 Adobe 账号；可用于游戏项目，具体以条款为准 |
| 图标 | game-icons.net | CC BY 3.0，**需要署名** |
| 音效 | Freesound、Kenney 音效包 | Freesound 每个文件授权不同（CC0 / CC BY 等） |
| 音乐 | itch.io、OpenGameArt | 授权各不相同，逐首确认 |
| 中文字体 | 思源 / Noto 系列等开源字体 | SIL OFL；商用标题字体要单独确认授权 |

AI 生成的概念图可以用来定风格，但不能直接当作 3D 模型使用；如果用 AI 生成贴图或图标，也要在清单里注明生成工具和使用条款。

## 13. 什么时候需要

| 时间 | 需要什么 | 原因 |
| --- | --- | --- |
| W1—W2（11/09—11/20） | **不需要正式素材** | 玩法在灰盒里开发；只需定下风格方向，挑一张整体参考图 |
| W2 末（约 11/20） | 样板：1 个角色 + 1 套动画 + 钟楼 + 符文锤 + 1 块 UI | 检查比例、滑步、中文显示、导航和性能（见原清单「到货 / 导入检查」） |
| W3（11/23—11/27） | 场景和道具批量替换；灯灵、显化特效；钟声 | 试玩前画面要能看懂 |
| W4 前（11/30） | 音乐、结局卡、汇报用录像 | 试玩和汇报 |

**最小可演示集合**（素材不够时只保这些）：4 个角色 + 待机 / 行走 / 交谈动画、钟楼、旧井、铁匠铺、旅店、符文锤、灯笼、灯灵和显化特效、钟声、对话框和回音石板 UI、一套中文字体。
